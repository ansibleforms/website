# Graphical User Interface

A visual tour of the AnsibleForms web interface, from the dashboard to advanced administration features.
{: .fs-6 .fw-300 }

---

Each screen is described on its own page:

* **[Login](login.html)** : the user authentication page with support for local, LDAP, Entra ID and OIDC authentication.
* **[The Dashboard](the-dashboard.html)** : the main dashboard displays all available forms organized by category.
* **[A Form](a-form.html)** : an example of a form with external data sources and dynamic fields.
* **[Form JSON Preview](form-json-preview.html)** : preview the JSON payload and extra variables passed to Ansible before you run the job.
* **[Running Job](running-job.html)** : real-time execution of an Ansible playbook with live output.
* **[Job Output](job-output.html)** : complete output from an executed Ansible playbook.
* **[Job Logs](job-logs.html)** : detailed job execution logs with timestamps and status information.
* **[Multi Step](multi-step.html)** : forms can be split into multiple steps for complex workflows.
* **[Builtin Designer](builtin-designer.html)** : visual form designer for creating and editing forms without coding.
* **[Schedules](schedules.html)** : schedule forms to run at specific times or intervals.
* **[Backups](backups.html)** : automated backup and restore functionality for forms and configurations.
* **[Restore](restore.html)** : restore forms and configurations from previous backups.
* **[Settings](settings.html)** : application settings and general configuration options.
* **[LDAP Configuration](ldap-configuration.html)** : configure LDAP/Active Directory authentication and authorization.
* **[LDAP Test](ldap-test.html)** : test the LDAP connection and query results.
* **[LDAP Test Output](ldap-test-output.html)** : detailed output from LDAP connection tests.
* **[Git Repositories](git-repositories.html)** : integrate with Git repositories to put your forms and playbooks under version control.
* **[Git Repository Editor](git-repository-editor.html)** : edit and configure Git repository integration settings.
* **[Log Viewer](log-viewer.html)** : built-in log viewer for troubleshooting and monitoring.
* **[Credential Manager](credential-manager.html)** : securely store and manage credentials used by playbooks.
* **[User Profile](user-profile.html)** : view and edit your user profile and preferences.
* **[Dark Mode](dark-mode.html)** : AnsibleForms supports dark mode for reduced eye strain.
* **[Swagger Interface](swagger-interface.html)** : interactive API documentation and testing via Swagger UI.
