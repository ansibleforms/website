{: .fs-6 .fw-300 }

1. TOC

---

For every user: your own account, preferences, password, permissions and API tokens.

Open your profile from the avatar at the top right: **Profile**.

---

## Opening a view

The left menu lists the profile's views in alphabetical order. Each view has its own address,
so you can link to it directly:

| View | Address |
|---|---|
| Account | `/profile?view=account` |
| API token | `/profile?view=token` |
| Password | `/profile?view=password` |
| Permissions | `/profile?view=permissions` |
| Preferences | `/profile?view=preferences` |

Views your roles do not allow are hidden; their address opens the first view instead.
