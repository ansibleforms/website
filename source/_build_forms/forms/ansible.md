## The repository a playbook runs from

Since 7.8.0 a form may name the repository its playbook runs from, with `playbookRepository`.

Without it, the playbook runs from the first repository used for playbooks, from its `playbooks` folder (else its root), as
before. With it, the playbook runs from the root of the repository named, so that repository's `ansible.cfg`, `roles/` and
relative inventory paths apply, and `playbook` is given from the root (`playbooks/site.yml`). The layout and a full example
are in [A repository in Ansible's own layout](../repositories/ansible-layout.html).
