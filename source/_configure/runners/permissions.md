# Who manages runners
{: .no_toc }

Who may add, change and test runners
{: .fs-6 .fw-300 }

A runner receives the credentials of every job it runs, so only the **admin** role adds, changes, turns on or off and deletes runners,
and approves or rejects an RTE that asked to join. Users with settings access see them and can test them, but cannot change them.

A runner declared in the [config seed](../seed/) is read only on this page: change it in the seed file instead.
