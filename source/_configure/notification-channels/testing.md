# Testing a channel
{: .no_toc }

Send test, and what it proves
{: .fs-6 .fw-300 }

**Send test** sends a test notification through the channel as saved, so save your changes first. It works on a channel
that is turned off too. For a mail channel
the dialog asks for the address to send to; the others post to their own channel. The dialog shows whether it worked,
and the reason when it did not.
