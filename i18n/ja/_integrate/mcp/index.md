# MCP サーバー
{: .no_toc }

Model Context Protocol を通じて、AI エージェントがフォームを使えるようにします
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

管理者とインテグレーター向けです。MCP クライアントが、保持しているトークンのユーザーとして、フォームを一覧表示し、入力し、起動できるようにします。

AnsibleForms は
[Model Context Protocol](https://modelcontextprotocol.io) サーバーを提供できます。これにより、チャットのバックエンドや IDE のアシスタントなどの
MCP クライアントが、ユーザーが使えるフォームを一覧表示し、そのフィールドを確定し、
ジョブを起動して進捗を追跡できます。

---

## これは何か、何でないか

MCP サーバーは、ブラウザーが使うのと同じフォームの流れへの技術的なインターフェースです。
**受け取ったトークンのユーザーとして** 動作します。フォームのロール、ジョブの可視性、
予約済みの extravars に対するチェックは、ブラウザーからの送信と同じです。

独自の AI ポリシーは何も加えません。起動の前にエージェントが確認を求めるべきかどうか、
どのフォームを使えるか、どれだけのリクエストを送れるかは、MCP クライアント次第です。
起動のツールは破壊的なものとしてマークされているため、行儀のよいクライアントはまず確認を求めますが、
サーバーがそれを強制することはありません。
