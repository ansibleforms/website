# 有効にする
{: .no_toc }

アシスタントを有効にし、フォームをアシスタントで使えるようにします
{: .fs-6 .fw-300 }

---

アシスタントを使うには、次の 4 つがすべて必要です。

1. **`ENABLE_CHAT=1`** : 環境変数です。設定ページで変更すると、再起動なしですぐに反映されます。オフの間は、
   チャットのエンドポイントは `404` を返します。 [`ENABLE_CHAT`](../customization/features.html#env_ENABLE_CHAT) を参照してください。
2. **モデルプロバイダー** : 設定 -> 接続 -> **チャットアシスタント** （Kubernetes では [設定シード](../seed) ）。
3. **対象となるフォーム** : 各フォームに `enableForChat: true` を指定します。アシスタントはそれ以外のフォームをすべて無視します。
4. **利用できるユーザー** : ロールのオプション `allowChat` （既定: true）。ロールに
   `allowChat: false` を設定すると、そのメンバーを除外できます。

4 つの条件がすべて満たされると、ユーザーにチャットボタンが表示されます。
