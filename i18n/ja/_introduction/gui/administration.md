## 「設定」メニュー

ヘッダーの **設定** で管理ページが開きます。管理ページは左メニューで **システム** 、 **外観** 、
**アクセス** 、 **接続** 、 **ログ** にまとめられています。各項目は、そのページに必要なロールのオプションを持つユーザーにだけ表示されます。
**バックアップ** には `allowBackupOps` 、 **サーバーログ** には `showLogs` 、それ以外のすべてのページには `showSettings` が必要です。
7.3.0 以降は、3 つのオプションでそれぞれ一部のページだけを開けます。

| ロールのオプション | 開くもの |
|---|---|
| `showAppearanceSettings` | **外観** のページ |
| `showConnectionsSettings` | **Syslog** を除く **接続** のページ。リポジトリ、シークレットストア、保護された認証情報の変更は引き続き管理者だけが行えます |
| `showAuditLog` | **監査ログ** |

ロールのオプションについては [ロール](../config/roles.html#role-options) を参照してください。

## 一覧とレコードのページ

7.3.0 以降、設定の一覧とレコードのページは共通のレイアウトになり、操作部品はタイトルの下の専用の行に並びます。

| 部分 | 動作 |
|---|---|
| 検索ボックス | すべての設定ページとレコードページで、その行の先頭にあります。語を入力するとすべてのタブが一度に絞り込まれ、一致したフィールド、行、ラインがそのタブの名前の下に表示されます |
| ページサイズ | ページサイズを選ぶまでは、表は画面に収まるだけの行を表示します。選べるのは 10、20、50、100 です |
| 列 | 名前のある列はすべて並べ替えでき、空のセルには `–` が表示されます |
| チェックボックス | チェックした行に対して何かできる場合にだけ行に表示され、行のメニュー（⋮）にも同じ操作があります |
| 行のメニュー | **編集** や **削除** のような短いラベルです。 **有効** 列を持つ一覧ではその列が先頭にあり、各行のメニューには状態に応じて **有効にする** または **無効にする** があります |

**有効** 列を持つ一覧は、SSO プロバイダー、LDAP ディレクトリ、ランナー、スケジュール、通知
チャネル、Syslog サーバー、お知らせ、ラベル、免責事項のバージョンです。

## システム

インスタンス自体の設定、状態、バックアップです。

| ページ | 用途 |
|---|---|
| **全般** | 環境変数。「設定」から「ロギング」までのタブに分かれています。 [環境変数](../customization/) を参照してください。 |
| **ステータス** | インスタンスとそれが依存するシステムの状態。「チェック」と「情報」のタブがあります。 [監視](../production/monitoring.html) を参照してください。 |
| **バックアップ** | データベース、config.yaml、フォームのバックアップの作成、復元、削除。 [バックアップ](../production/backups.html) を参照してください。 |

![設定 > 全般の「設定」タブ](../assets/screenshots/settings.jpg)

### バックアップ

夜間と手動のバックアップの一覧です。 **バックアップを追加** で今すぐバックアップを取り、行のメニューには **バックアップを表示** 、 **復元** 、 **削除** があります。

![設定 > バックアップ](../assets/screenshots/backups.jpg)

### 復元

**復元** はバックアップの内容を表示してから復元します。 **復元する前に新しいバックアップを作成する (推奨)** は既定でチェックされています。

![バックアップの復元](../assets/screenshots/restore.jpg)

## 外観

すべての人に対するインスタンスの見た目と、表示するメッセージです。

| ページ | 用途 |
|---|---|
| **既定値** | 何も選んでいないユーザーのテーマ、言語、フォームの表示、タイムゾーン、日付の形式。 [既定値](../appearance/defaults.html) を参照してください。 |
| **名前** | ブラウザーのタブとサインインページに表示される名前。 [名前](../appearance/name.html) を参照してください。 |
| **ロゴ** | ヘッダーに表示する独自のロゴ。 [ロゴ](../appearance/logo.html) を参照してください。 |
| **アイコン** | ブラウザーのタブに表示する独自のアイコン。 [アイコン](../appearance/icon.html) を参照してください。 |
| **リンク** | デザイナーへのリンクと、ヘッダーに置く独自のリンクやメニュー。 [リンク](../appearance/links.html) を参照してください。 |
| **ラベル** | ロゴの横に表示する PRODUCTION や EU などのラベル。 [ラベル](../appearance/labels.html) を参照してください。 |
| **お知らせ** | ヘッダーの下に、開始から終了まで表示するメッセージ。 [お知らせ](../announcements.html) を参照してください。 |

## アクセス

誰がサインインでき、サインインした後に何ができるかです。

| ページ | 用途 |
|---|---|
| **免責事項** | すべてのユーザーが一度同意する条項と、誰がどのバージョンに同意したか。 [免責事項](../disclaimer.html) を参照してください。 |
| **ユーザー** | ローカルユーザー、LDAP とシングルサインオンのユーザー。 [ユーザーとグループ](../users-and-groups.html) を参照してください。 |
| **グループ** | ローカルグループ、LDAP とシングルサインオンのグループ。 [ユーザーとグループ](../users-and-groups/local-group.html) を参照してください。 |
| **ロール** | config.yaml のロール。誰が持っていて、何を許可するか。 [ロール](../config/roles.html) を参照してください。 |
| **LDAP** | LDAP ディレクトリまたは Active Directory でのサインイン。 [LDAP](../authentication/ldap.html) を参照してください。 |
| **SSO** | Entra ID または OpenID Connect プロバイダーでのシングルサインオン。 [認証](../authentication/) を参照してください。 |

![アクセス > LDAP、メインのディレクトリ](../assets/screenshots/ldap.jpg)

## 接続

AnsibleForms が接続するシステムと、それらにログインするためのものです。

| ページ | 用途 |
|---|---|
| **リポジトリ** | フォームとプレイブックの取得元となる Git リポジトリ。 [Git リポジトリ](../repositories/) を参照してください。 |
| **認証情報** | フォーム、プレイブック、接続が使うアカウントとシークレット。 [認証情報](../credentials.html) を参照してください。 |
| **シークレットストア** | 認証情報を読み取れる HashiCorp Vault と CyberArk。 [シークレットストア](../secret-stores/) を参照してください。 |
| **ランナー** | ジョブの実行場所。プレイブック用の RTE コンテナーと、テンプレート用の AWX などです。 [ランナー](../runners.html) を参照してください。 |
| **SSH** | アプリが Git に接続するときに使う鍵ペアと、既知のホスト。 [SSH](../repositories/authentication.html#ssh-with-the-generated-key) を参照してください。 |
| **通知** | SMTP サーバー、Slack、Microsoft Teams、Telegram、Webhook。 [通知チャネル](../notification-channels.html) を参照してください。 |
| **チャットアシスタント** | チャットアシスタントの AI プロバイダー。 [チャットアシスタント](../chat/) を参照してください。 |
| **MCP** | AI エージェント用の MCP サーバー。 [MCP](../mcp/) を参照してください。 |
| **Syslog** | サーバーログ、監査ログ、またはその両方を受け取る Syslog サーバー。 [Syslog](../production/logs.html#syslog) を参照してください。 |

![接続 > 認証情報、認証情報の「接続」タブ](../assets/screenshots/credentials.jpg)

## ログ

インスタンスで何が起きたかです。

| ページ | 用途 |
|---|---|
| **監査ログ** | 誰が何を変更し、それが許可されたかどうか。ユーザー、アクション、結果で絞り込めます。 [監査証跡](../production/logs.html#audit-trail) を参照してください。 |
| **サーバーログ** | トラブルシューティング用のサーバー自身のログ。 [ログ](../production/logs.html) を参照してください。 |

### サーバーログ

ログの最後の数行で、最新の行がいちばん下にあり、書き込まれるにつれて追従します。検索ボックスで絞り込め（正規
表現）、 **クリア** はログではなく表示を空にし、 **ダウンロード** はログ全体を保存します。

![ログ > サーバーログ](../assets/screenshots/logs.jpg)
