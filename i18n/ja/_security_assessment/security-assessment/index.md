# セキュリティ評価
{: .no_toc }

セキュリティレビュー向け: 対策、開発、アドバイザリ
{: .fs-6 .fw-300 }

---

## 要約

AnsibleForms は playbook を実行し、その認証情報を保持するため、信頼の連鎖の一部になります。

* **セルフホスト型** です。お使いのインフラストラクチャ上で動作し、データはお使いのデータベースに保存され、開発者には何も送信しません。
* **オープンソース** (GPL-3.0) です。コード、パイプライン、すべてのアドバイザリが公開されています。
* 保存されるシークレットはすべて **暗号化** され、すべての変更は **監査** され、リクエストごとに **ロール** がチェックされます。
* 脆弱性は **非公開で報告** され、サポート対象のすべてのリリースで修正され、 **公開** されます。

## このセクションの内容

各ページでは、設計から CVE の一覧まで、セキュリティレビューで問われる質問に答えています。

| ページ | 内容 |
|---|---|
| [セキュリティ対策](measures.html) | サインイン、権限、保存されたシークレット、監査証跡、ブラウザー、サーバー、接続、コンテナー |
| [セキュアな開発](development.html) | 変更のレビューとテストの方法、コードと依存関係の分析、イメージのビルド方法、サポート対象のバージョン |
| [脆弱性の報告](reporting.html) | 問題を非公開で報告する方法と、その後の流れ |
| [セキュリティアドバイザリ](advisories.html) | 公開されたすべての脆弱性と、その CVE、深刻度、修正バージョン |
| [評価に関する FAQ](faq.html) | セキュリティ質問票でよく聞かれる質問への簡潔な回答 |

インスタンスを評価するのではなく保護したい場合は、管理者ガイドの [セキュリティ](../security/) を参照してください。
