## 保存済みジョブ

保存済みジョブはフォームの値を保存しておくもので、毎回同じフィールドに入力する代わりに、その値を再び読み込めます。

保存するには、フォームに入力し、 **送信** の横のドロップダウンを開いて **ストア** を選びます。 **フォームデータを保存** で **名前** 、任意の **説明** 、いつ削除するか ( **削除** 。 [削除されるタイミング](#when-it-is-removed) を参照) を入力して保存します。パスワードと定数のフィールドは保存されません。サブフォームにも **保存** ボタンの横に同じ **ストア** 操作があり、入力途中の値を検証せずに保存します。

読み込むには、フォームの上部で **保存済みデータから読み込む** を選びます。 **保存したフォームを読み込む** に、そのフォームの保存済みジョブが
作成日と有効期限とともに一覧表示されます。1 つ選ぶと、その値がフォームに入力されます。送信するまで何も実行されません。

保存済みジョブは AnsibleForms のデータベース (テーブル `stored_jobs` ) に、フォーム名、 `<type>/<username>` 形式のユーザー
(たとえば `local/admin` )、JSON 形式の値とともに保存されます。名前はユーザーとフォームごとに一意である必要があり、
同じ名前で 2 つ目を保存しようとすると「A saved form with this name already exists」で失敗します。

## 保存済みジョブを管理する

**保存済みジョブ** ページには、保存済みジョブがフォーム、ユーザー、作成日、有効期限とともに一覧表示されます。 `allowStoredJobs` が必要です。

7.6.0 からは、 `allowStoredJobs` だけで **ジョブ > 保存済み** と **保存済みジョブを追加** を開けます。以前は `showSettings` または
`allowScheduledJobs` も必要でした。 **フォーム** の一覧には、自分のロールで開けるフォームが表示されます。 `showSettings` または `allowScheduledJobs` を持つユーザーにはすべてのフォームが表示されます。

7.7.0 からは一覧に並べ替え可能な **最終使用** 列があり、まだ使われている保存済みジョブと放置されたものを見分けられます。

- **編集** で、保存済みジョブ自体のページを開きます。 **詳細** (名前、説明、フォーム、ユーザー、作成日時と最終使用日時、削除されるタイミング)、 **値** (保存された
  フィールド値の YAML。そこで変更して保存できます)、 **実行履歴** があります。
- **フォームで開く** で、保存された値を入力した状態でフォームを開きます。送信するまで何も実行されません。
- **削除** で削除します。自分の保存済みジョブは削除でき、 `showSettings` を持つユーザーはどれでも削除できます。

## 最終使用と実行履歴

7.7.0 から、保存済みジョブは最後に使われた日時と、そこから起動されたジョブを記録するため、どれがまだ使われているかがわかります。

次の起動が保存済みジョブの使用として数えられます。

| 起動 | 数えられるタイミング |
|---|---|
| そこから開いたフォーム ( **フォームで開く** )、または **保存済みデータから読み込む** で入力したフォーム | ジョブが起動されたとき |
| そのフォームからの **後で実行** | 計画した実行が始まったとき。計画したときではありません |
| そこから起動したジョブの **再実行** | 再実行が始まったとき。値が同じでも変更していても数えられます |
| それを指定した MCP の `launch_job` または `plan_job` | 上と同じ |

スケジュールの実行は、保存済みジョブから作ったスケジュールであっても数えられません。スケジュールは値の独自のコピーを持つためです。起動が数えられるのは、ユーザーがその保存済みジョブを見られる場合だけです。その後に削除されたり見えなくなったりしたものはスキップされ、ジョブはそのまま実行されます。

ジョブのページには、起動元の保存済みジョブが、見られる場合はリンク付きで表示されます。保存済みジョブのページの **実行履歴** タブには、そこから起動されたジョブのうち見られるものが、状態、開始、終了、所要時間とともに一覧表示されます。

## 削除されるタイミング

保存済みジョブの削除のタイミングは、しない、指定日、一定日数の未使用後のいずれかです。

| 選択肢 | 動作 |
|---|---|
| **しない** | だれかが削除するまで残します。 `STORED_JOB_UNUSED_DAYS` が設定されている間は選べません |
| **指定日に** | その日に削除します |
| **未使用の期間** N 日 | そこから N 日間ジョブが起動されなかったら削除します |

管理者は [`STORED_JOB_UNUSED_DAYS`](../customization/retention.html#env_STORED_JOB_UNUSED_DAYS) (設定 > 全般 > 保持期間) を設定できます。設定すると、その日数使われなかった保存済みジョブはすべて削除され、保存済みジョブ自身の日数はそれより少なくしか設定できず、ストアのダイアログはその日数から始まり、指定日に削除するものもその期間使われなければ削除されます。日数は最後の使用から、一度も使われていない保存済みジョブは保存した時点から数えます。既定値の 0 では、未使用を理由に削除されることはありません。

保存済みジョブは毎日 04:00 ( `LOG_TZ` ) に、日付と日数のうち早いほうが来たときに削除されます。
