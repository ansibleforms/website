# パスワード
{: .no_toc }

ローカルアカウントのパスワードを変更する
{: .fs-6 .fw-300 }

---

現在のパスワードと新しいパスワードを 2 回入力し、 **パスワードの変更** をクリックします。

LDAP、Entra ID、OpenID Connect のアカウントは、それぞれのプロバイダー側でパスワードを変更します。
