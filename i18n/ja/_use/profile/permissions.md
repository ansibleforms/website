# 権限
{: .no_toc }

ロールで何が許可されているか
{: .fs-6 .fw-300 }

---

ロールオプションはタブごとにまとめられており、各タブには、そのタブのオプションのうち自分が持っている数が `5/8` のように表示されます。

| タブ | 対象のオプション |
|---|---|
| **アクセスと連携** | サインイン、チャットアシスタント、MCP サーバー、ファイルのアップロード、API トークン |
| **デザイナー** | デザイナーを開くこと、およびフォーム、playbook、ワークフロー、インベントリ、変数ファイルの編集 |
| **ジョブ** | ジョブとその extravars やアーティファクトの表示、再起動、削除、スケジュール設定、ジョブの保存 |
| **設定** | 設定ページ、ログ、監査ログ、バックアップ |
| **その他** | ロールに手動で設定した、ほかのどのタブにも属さないオプション。常に最後のタブです |

それ以外のタブはアルファベット順に並びます。各タブは表になっており、 **設定** (オプション)、 **説明**
(その働き)、 **あなたのアクセス権** ( **許可** または **不許可** ) の列があります。別のオプションによって適用されるオプションには、
説明の下にその旨が表示されます。 **〜に含まれます** は、持っているオプションによって有効になっていることを、 **〜が必要です** は、持っていないオプションのために無効のままであることを示します。

オプションは `config.yaml` にあるロールの `options` から決まります。オプションがどう組み合わされるかは
[ロール](../config/roles.html) のページで説明しています。
