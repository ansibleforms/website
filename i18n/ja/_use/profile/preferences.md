## 個人設定の項目

個人設定ビューでは、自分に対する AnsibleForms の見た目を変更できます。それぞれの選択は、設定を行ったブラウザーに
保存されるため、別のブラウザーやコンピューターでは既定値から始まります。

| 設定 | 選択肢 | ほかに設定できる場所 |
|---|---|---|
| 言語 | Català、Deutsch、English、Español、Français、Italiano、Nederlands、Polski、Português、日本語、简体中文 (簡体字中国語) | ヘッダーの国旗 |
| テーマ | ブラウザーに合わせる、ライト、ダーク、色 (選んだ色のヘッダー) | ヘッダーの太陽アイコン |
| フォームの表示 | タイルまたはリスト | フォームページのボタン |
| タイムゾーン | UTC、このブラウザーのタイムゾーン、または名前で指定した任意のタイムゾーン | ここのみ |
| 日付形式 | `YYYY-MM-DD`、 `DD/MM/YYYY`、 `MM/DD/YYYY`、 `DD.MM.YYYY` | ここのみ |
| デスクトップ通知 | オンまたはオフ | ここのみ |

7.3.0 以降、このビューはタブに分かれており、各タブに固有のアドレス ( `/profile/preferences/<tab>` ) があります。 **外観** (言語、テーマ、フォームの
表示)、 **日付と時刻** (タイムゾーンと日付形式)、 **通知** の 3 つです。上の検索ボックスには、一致する設定がタブ名の下に
一覧表示されます。選択内容は **保存** するまで下書きのままで、変更を保存せずにビューを離れようとすると確認を求められます。

**ブラウザーに合わせる** は、ブラウザーと同じようにライトまたはダークに切り替わり、ブラウザーの変更にも追従します。7.3.0 以降の既定のテーマで、
管理者が別のテーマを選んでいない限りこれが使われます。 **色** テーマの色にポインターを合わせると、ここでもヘッダーのテーマメニューでも、その色でアプリを
プレビューでき、ポインターがパレットから離れると元のテーマに戻ります。クリックするまでは何も変わりません。

## デスクトップ通知

7.3.0 以降、 **通知** タブでは、ロールで `showJobs` が設定されているユーザーに対して、このブラウザーでのデスクトップ通知を有効にできます。

初回はブラウザーが許可を求めます。ブラウザーがこのサイトの通知をブロックしている場合、スイッチはオフのままになり、許可する方法が
表示されます。また、通常の `http` のサイトでは通知をまったく表示できません。有効にすると、次のときに通知が届きます。

| タイミング | 内容 | クリックしたとき |
|---|---|---|
| 自分が起動したジョブが終了したとき | フォームとその結果 ( *Patch Linux servers: 成功* など)、ジョブ番号、所要時間 | そのジョブを表示した状態でタブを前面に出します |
| ジョブが自分の承認を待っているとき | フォーム、ジョブ番号、起動したユーザー、 **承認** ボタンと **拒否** ボタン | 承認待ちのジョブを開きます |

**承認** ボタンと **拒否** ボタンは Chrome と Edge で表示されます。Firefox と Safari ではボタンなしで通知が表示され、自己署名証明書を使った
サイトでも同様です。ボタンには Service Worker が必要なためです。通知が届くのは、AnsibleForms のタブが開いている間だけです (バックグラウンドでもかまいません)。
タブをすべて閉じると何も送られません。開いているタブの数にかかわらず、各通知は 1 回だけ表示されます。また、マルチステップ
ジョブの各ステップと、現在表示しているジョブについては通知されません。

## タイムゾーン

AnsibleForms 全体の日付と時刻は、選択したタイムゾーンで表示されます。対象には、ジョブの開始
時刻と終了時刻、監査ログ、ステータスページ、バックアップ、保存済みジョブ、API
トークンの有効期限が含まれます。タイムゾーンを変更すると、再読み込みしなくてもすべてのページがすぐに更新されます。

自分で選ぶまでは、管理者が全員向けに設定したタイムゾーンが適用されます ( **設定 > 外観 > 既定値** 、
[外観](../appearance.html) を参照)。変更されていなければ **UTC** です。 **このブラウザー** はコンピューターのタイムゾーンに従い、
一覧には `Europe/Madrid` のように名前ですべてのタイムゾーンが含まれます。カードには、選択したタイムゾーンと形式での現在時刻が表示されます。

## 日付形式

日付形式では、すべての日付の日付部分の表記を設定します。各選択肢は今日の日付で表示されます: `YYYY-MM-DD`
(2026-10-12)、 `DD/MM/YYYY`、 `MM/DD/YYYY`、 `DD.MM.YYYY`。自分で選ぶまでは管理者の既定の日付形式が
適用され、変更されていなければ `YYYY-MM-DD` です。ほかの選択と同様に、このブラウザーに保存されます。

---

## サーバーの時刻のまま表示されるもの

次の 2 つは例外で、サーバー自体の時刻のまま表示されます。

- **サーバーログとジョブの出力** は、サーバーが書き込んだ時刻を含むテキストです。
- **自分で入力する時刻** (予定したジョブの実行時刻など) と cron スケジュールは、
  これまでどおりに動作します。
