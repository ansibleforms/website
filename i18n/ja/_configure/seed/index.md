# 構成シード
{: .no_toc }

管理オブジェクトをファイルで宣言します
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

git から構築する管理者向けです。管理オブジェクトをファイルで宣言し、空のデータベースからインスタンスを再構築できるようにします。

---

## 対象となるもの

`CONFIG_SEED_PATH` に YAML ファイルを設定すると、AnsibleForms は起動時にそれを適用します。このファイルは、
それ以外ではデータベースにしか存在しないオブジェクトと設定を宣言します。

| セクション           | 宣言するもの                                                                      |
|--------------------|-----------------------------------------------------------------------------------|
| `runners`          | ジョブの実行場所：RTE、AWX / AAP / Ascender、Semaphore、Rundeck、Jenkins           |
| `secret_stores`    | シークレットストア（HashiCorp Vault など）                                          |
| `credentials`      | 認証情報                                                                          |
| `databases`        | フォームが照会するデータベースとその認証情報（7.5.0 から）                           |
| `sso`              | SSO プロバイダー：Entra ID と OIDC（7.8.0 より前は `oauth2`）                       |
| `repositories`     | Git リポジトリと、アプリがそれぞれから読み込むもの                                   |
| `syslog`           | サーバーログと監査エントリを受け取る syslog サーバー（7.8.0 より前は `syslog_servers`） |
| `notifications`    | メールサーバー、Slack、Teams、Telegram、Webhook（7.8.0 より前は `notification_channels`） |
| `labels`           | ヘッダーのロゴの横のラベル（7.3.0 から）                                             |
| `ldap`             | LDAP の設定                                                                       |
| `settings`         | 公開 URL。メールのキーは 7.6.0 から非推奨で、メールチャネルに代わりました              |
| `chat_assistant`   | チャットアシスタントのモデルプロバイダー（7.8.0 より前は `chat`）                     |
| `users`            | ローカルとディレクトリのユーザー（7.8.0 から）                                       |
| `groups`           | ローカルグループとそのメンバー（7.8.0 から）                                         |
| `defaults`         | **設定 > 外観 > 既定値** ：テーマ、言語、タイムゾーン（7.8.0 から）                   |
| `logo` 、 `icon`   | ロゴと Web サイトのアイコン。シードの隣の画像ファイル（7.8.0 から）                   |
| `name`             | アプリの名前（7.8.0 から）                                                          |
| `links`            | ヘッダーのリンクと、デザイナーのリンクを表示するかどうか（7.8.0 から）                 |
| `announcements`    | ヘッダーの下のお知らせ（7.8.0 から）                                                |
| `disclaimer`       | ユーザーが同意する免責事項のバージョン（7.8.0 から）                                  |
| `mcp`              | MCP サーバーのスイッチ（7.8.0 から）                                                |
| `ssh`              | アプリの SSH 秘密鍵とその既知のホスト（7.8.0 から）                                   |
| `awx`              | 7 から非推奨、8 で削除： `type: awx` の `runners` を使ってください                    |

[例](example.html) ではすべてのセクションを示し、 [管理対象オブジェクト](managed-objects.html) では各セクションが宣言したものをシードがどこまで
所有するかを説明します。ほとんどのセクションはそのオブジェクトをアプリで読み取り専用にし、いくつかは作成または変更するだけです。

バージョン 7 より前に書かれたシードも引き続き動作します。 `awx` セクションの各項目は種類 `awx` のランナーとして適用され、ログには
適用のたびに警告が出ます。8 にアップグレードする前に、それらの項目を `type: awx` として `runners` の下に移してください。

シードは、カテゴリ、ロール、定数の基本構成である `config.yaml` （ `CONFIG_PATH` ）と同じでは **ありません** 。代わりにリポジトリが
それらを保持することもでき、そのリポジトリはシードが宣言するオブジェクトの一つなので、シードをその中に置くことはできません。

最初の管理者は引き続き `ADMIN_USERNAME` / `ADMIN_PASSWORD` から作成され、LDAP や SSO のユーザーはサインイン時にそのディレクトリから取得されます。
7.8.0 からは、 `users` と `groups` セクションでローカルのユーザーとグループを追加し、ディレクトリのユーザーをサインイン前にブロックできます。

---

## 名前が変わったセクション

7.8.0 から、四つのセクションは、 [git リポジトリ](../repositories/) が同じオブジェクトを保持するキーから `controller_` を除いた名前に
なりました（ `controller_sso:` に対して `sso:` ）。

| 7.8.0 より前              | 7.8.0 から         |
|---------------------------|--------------------|
| `oauth2:`                 | `sso:`             |
| `syslog_servers:`         | `syslog:`          |
| `notification_channels:`  | `notifications:`   |
| `chat:`                   | `chat_assistant:`  |

項目は変わりません。古い名前も引き続き読み込まれますが、7.8.0 から非推奨で、8 で削除されます。古い名前で適用されるたびに、
新しい名前を示す警告がサーバーログに出ます。一つのセクションを両方の名前で指定したシードは拒否されます。8 にアップグレードする前に、
ファイル内の名前を変更してください。
