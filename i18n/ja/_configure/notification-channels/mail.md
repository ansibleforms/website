# メール
{: .no_toc }

SMTP サーバー、既定のサーバー、そのログイン
{: .fs-6 .fw-300 }

メールチャネルは SMTP サーバーです。複数持つことができ、 **既定** の印が付いたものが、フォームがメールチャネルを指定していないときに
アプリがメールの送信に使うサーバーです。最初のメールチャネルが既定になり、 **既定にする** で変更できます。

| ステップ | フィールド | 意味 |
|---|---|---|
| 認証情報 | 認証情報 | 必須。 [接続 > 認証情報](../credentials.html) の **smtp** 認証情報で、メールサーバー、そのポートと TLS、ログインを保持します。ログインのないリレーの場合は、ユーザーのない smtp 認証情報を使います。 |
| 送信者 | 送信元アドレス | 受信者に表示される送信者のアドレス。 |

メールチャネルのページの **詳細** タブにある **既定** スイッチは、 **既定にする** と同じく、そのチャネルを既定にします。
既定のメールチャネルがない間、または既定のものがオフになっている間は、構成シードのメール設定が使われます。
