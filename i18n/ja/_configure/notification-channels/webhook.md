# Webhook
{: .no_toc }

任意の HTTP エンドポイントへの JSON リクエスト
{: .fs-6 .fw-300 }

Webhook チャネルは、任意の HTTP エンドポイントに JSON リクエストを送ります。 **エンドポイント** ステップで送信先と方法を指定し、
**認証情報** ステップには **Bearer トークン** があります。

| フィールド | 意味 |
|---|---|
| URL | リクエストの送信先アドレス。 |
| メソッド | `POST` （既定）または `PUT` 。 |
| Bearer トークン | [接続 > 認証情報](../credentials.html) の **api** 認証情報で、そのパスワードが `Authorization: Bearer <password>` として送られます。空の場合はトークンなし。 |
| TLS 証明書を検証 | 既定でオンです。自己署名証明書のエンドポイントの場合にのみオフにします。 |

{% raw %}
**ペイロード** ステップには、 `{ "X-Source": "ansibleforms" }` のような JSON オブジェクトで指定する追加のヘッダーである **ヘッダー** と、
本文の JSON テンプレートである **ペイロード** があります。次のプレースホルダーが埋め込まれます。

| プレースホルダー | 値 |
|---|---|
| `{{title}}` | 通知のタイトル |
| `{{text}}` | 通知の本文 |
| `{{status}}` | ジョブのステータス |
| `{{event}}` | ジョブのイベント |
| `{{jobId}}` | ジョブ ID |
| `{{form}}` | フォーム名 |
| `{{user}}` | ジョブを開始したユーザー |
| `{{link}}` | ジョブへのリンク |

JSON の文字列全体であるプレースホルダー（ `"{{text}}"` ）は、値を JSON としたものに置き換えられます。より長い文字列の中では、
そのテキストは JSON 用にエスケープされます。不明なプレースホルダーは書かれたまま残ります。ペイロードが空の場合は、次のテンプレートが送られます。

```json
{
  "title": "{{title}}",
  "text": "{{text}}",
  "status": "{{status}}",
  "event": "{{event}}",
  "job": { "id": "{{jobId}}", "form": "{{form}}", "user": "{{user}}" },
  "link": "{{link}}"
}
```
