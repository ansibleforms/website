# チャネルのテスト
{: .no_toc }

テスト送信と、それで確認できること
{: .fs-6 .fw-300 }

**テスト送信** は、保存されている状態のチャネルでテスト通知を送るので、先に変更を保存してください。オフになっているチャネルでも
使えます。メールチャネルの場合は
ダイアログで送信先のアドレスを尋ねられます。ほかのチャネルは自分のチャネルに投稿します。ダイアログには成功したかどうかと、
失敗した場合はその理由が表示されます。
