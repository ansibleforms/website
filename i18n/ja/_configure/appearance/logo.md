# ロゴ
{: .no_toc }

ヘッダーに表示する独自のロゴ
{: .fs-6 .fw-300 }

**ロゴ** では、ヘッダーの AnsibleForms のロゴを独自の画像に置き換えます。画像はすべてのテーマで表示されます。

| ルール | 値 |
|---|---|
| 形式 | PNG、JPEG、WEBP、GIF、SVG |
| 最大ファイルサイズ | 900 KB |
| ヘッダーでのサイズ | 最大 200 × 33 px。縦横比は維持されます |

**新しいロゴ** でファイルを選ぶとプレビューが表示されるので、 **アップロード** をクリックします。 **現在のロゴ** には、使用中のロゴと
ヘッダーでの表示サイズが表示されます。 **カスタムロゴを削除** を押すと、テーマに合わせて変わる既定のロゴに戻ります。
