# 名前
{: .no_toc }

ブラウザーのタブとサインインページに表示されるアプリケーション名
{: .fs-6 .fw-300 }

**名前** には、ブラウザーのタブとサインインページに表示される **アプリケーション名** を設定します。空の場合、ブラウザーのタブには
`AnsibleForms` と表示され、サインインページには名前が表示されません。
