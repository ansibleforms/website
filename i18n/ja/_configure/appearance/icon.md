# アイコン
{: .no_toc }

ブラウザーのタブとブックマークに表示する独自のアイコン
{: .fs-6 .fw-300 }

**アイコン** では、ブラウザーのタブとブックマークに表示される AnsibleForms のアイコンを置き換えます。

| ルール | 値 |
|---|---|
| 形式 | PNG、ICO、SVG、WEBP、GIF、JPEG |
| 最大ファイルサイズ | 256 KB |
| 最適な結果 | 64 × 64 px 以上の正方形の画像、または SVG |

**新しいアイコン** でファイルを選び、 **アップロード** をクリックします。 **カスタムアイコンを削除** を押すと既定のアイコンに戻ります。
