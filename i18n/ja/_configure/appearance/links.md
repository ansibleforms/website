# リンク
{: .no_toc }

ヘッダーのリンク（組み込みと独自のもの）
{: .fs-6 .fw-300 }

**リンク** では、サインインしているすべてのユーザーに対するヘッダーのリンクを、二つのタブで設定します。

**組み込み** には **デザイナー** スイッチがあります。 [`SHOW_DESIGNER`](../customization/features.html#env_SHOW_DESIGNER) に保存され、
再起動なしで反映されます。オフにすると、デザイナーは全員に対してなくなります。リンクも、ページも、API もです。

**カスタム** には、Wiki、Runbook、サポートポータルなどの独自のリンクを置きます。 **リンクを追加** を押すと、次のフィールドを持つ行が追加されます。

| フィールド | 意味 |
|---|---|
| **アイコン** | ラベルの前に表示するアイコン。リストから選びます |
| **ラベル** | リンクのテキスト |
| **アドレス** | サイト（ `https://…` ）またはアプリのページ（ `/forms/all` ） |
| **新しいタブ** | リンクをブラウザーの新しいタブで開きます |

行のボタンで行を移動します。 **→** はリンクを上のリンクの中に入れ、上のリンクはヘッダーでメニューとして開くようになります。
**←** はリンクをヘッダーに戻し、上下の矢印はリンク（中にリンクを持つメニューならメニューごと）を移動します。
メニュー自体にはアドレスは不要です。

ヘッダーには、組み込みのリンクの後に独自のリンクを最大 5 個、各メニューの中には最大 10 個まで置けます。
