# ローカルグループ
{: .no_toc }

ローカルグループのページとそのタブ
{: .fs-6 .fw-300 }

グループのページ `/settings/groups/<id>` には、次のタブがあります。

| タブ | 表示内容 |
|---|---|
| **詳細** | 名前と説明 |
| **ユーザー** | グループのユーザー。 **ユーザーを追加** で追加し、行のメニューまたはチェックボックスで外します |
| **ロール** | そのグループを指定しているロール |
| **フォーム** | それらのロールで開けるフォーム |

ユーザーのいるグループは削除できません。先にユーザーを外してください。 `admins` グループは削除も名前の変更もできません。
