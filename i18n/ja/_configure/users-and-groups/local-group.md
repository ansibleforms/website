# ローカルグループ
{: .no_toc }

ローカルグループのページとそのタブ
{: .fs-6 .fw-300 }

7.8.0 から、 **グループを追加** を押すと 3 ステップの **新しいグループ** ウィザードが開きます。 **詳細** （名前と説明）、 **ユーザー**
（グループに入れるローカルユーザー）、 **ロール** （グループに与え、そのユーザーが持つことになるロール）です。必須なのは名前だけです。最後のステップの
**保存** でグループを作成し、続けてユーザーを追加してロールを与えます。失敗したものはメッセージで示され、グループはそのまま残ります。

グループのページ `/settings/groups/<id>` には、次のタブがあります。

| タブ | 表示内容 |
|---|---|
| **詳細** | 名前と説明 |
| **ユーザー** | グループのユーザー。 **ユーザーを追加** で追加し、行のメニューまたはチェックボックスで外します |
| **ロール** | そのグループを指定しているロール |
| **フォーム** | それらのロールで開けるフォーム |

ユーザーのいるグループは削除できません。先にユーザーを外してください。 `admins` グループは削除も名前の変更もできません。
