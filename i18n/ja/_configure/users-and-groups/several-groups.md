# 複数のグループ
{: .no_toc }

複数のグループに所属するローカルユーザーと、そのロール
{: .fs-6 .fw-300 }

ローカルユーザーは複数のグループに所属でき、そのすべてのグループのロールが付与されます。ロールではグループを `local/<group>` と指定します。

**グループ** タブでは、 **グループを追加** でユーザーを別のグループに追加し、行のメニューまたはチェックボックスで外します。
ユーザーには少なくとも一つのグループが残ります。ユーザーのリストでは、各行のメニューにある **グループに追加** で同じことができます。
