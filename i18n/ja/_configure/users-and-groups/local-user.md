# ローカルユーザー
{: .no_toc }

ローカルユーザーの追加と、そのページのタブ
{: .fs-6 .fw-300 }

**ユーザーを追加** を押すと、3 ステップのウィザードが開きます： **ユーザー** （ユーザー名、説明、メールアドレス）、 **パスワード** 、 **グループ** 。

ユーザーのページ `/settings/users/<id>` には、次のタブがあります。

| タブ | 表示内容 |
|---|---|
| **詳細** | **サインインを許可** スイッチ、ユーザー名、説明、メールアドレス、そして 7.3.0 からは **最終サインイン** |
| **グループ** | ユーザーが所属するグループ |
| **ロール** | ユーザーが持つロールと、それぞれを与えているもの： **直接** 、グループ **経由** 、または **全員** |
| **フォーム** | それらのロールで開けるフォーム |
| **ジョブ** | ユーザーが起動したジョブ。新しい順 |
| **保存済みジョブ** | ユーザーが再実行用に保存したフォームの値 |
| **スケジュール** | ユーザーが後で実行で計画したジョブ |
| **アクティビティ** | 監査ログに記録されたユーザーの操作 |
| **API トークン** | ユーザーの API トークンと、それぞれの作成日時、有効期限、最終使用日時。 **取り消す** で一つをすぐに終了します |

7.3.0 からは、LDAP や SSO のユーザーと同じく、ローカルユーザーのサインインも記録されます。 **最終サインイン** には最新のものが表示され、
ユーザーのリストにはすべてのソースについて並べ替え可能な **最終サインイン** 列があるので、誰も使っていないアカウントが目立ちます。拒否されたサインインは
記録されず、アップグレード以降サインインしていないローカルユーザーには `–` が表示されます。

右上に **パスワードの変更** と **削除** があります。ユーザー `admin` は削除も名前の変更もできません。
