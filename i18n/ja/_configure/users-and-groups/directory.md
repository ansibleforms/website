# ディレクトリのユーザーとグループ
{: .no_toc }

最後に確認された状態の、LDAP、Entra ID、OIDC のユーザーとグループ
{: .fs-6 .fw-300 }

LDAP、Entra ID、OIDC のユーザーのページは `/settings/users/<source>/<name>` にあり、ソースは `ldap` 、 `azuread` 、 `oidc` のいずれかです。
たとえば `/settings/users/ldap/jdoe` です。ページには、ユーザーの最後のサインイン時に記録された内容が読み取り専用で表示されます。
ユーザーが誰であるかとそのグループは、ディレクトリまたは ID プロバイダーが管理しているためです。

タブはローカルユーザーと同じです。 **詳細** には **サインインを許可** スイッチ、ユーザー名、ソース、名前、
メールアドレス、ユーザーが初めて確認された日時（初回確認）、最終サインインがあります。 **グループ** には最後のサインインのグループが表示されます。
**API トークン** にはユーザーの API トークンが表示され、 **取り消す** で一つをすぐに終了します。

右上の **セッションを終了** は、ユーザーをすべての場所から今すぐサインアウトさせます。 **削除** はレコードを削除しますが、レコードは
次のサインインで戻ってきます。そのジョブ、保存済みジョブ、スケジュールは残ります。ブロックされたユーザーは削除できません。
削除すると再び入れてしまうためです。サーバーは `409` を返すので、先にサインインを許可してください。

このレコードのグループは、ユーザーのセッションがライブで読み込んで使うグループでもあります。サインイン中のユーザーを削除すると、
再びサインインするまで、グループも、そのグループが与えるロールも持たない状態になります。

ディレクトリのグループのページは `/settings/groups/<source>/<name>` にあり、読み取り専用で、タブは **詳細** 、
**ユーザー** （最後のサインイン時にそのグループで確認されたユーザー）、 **ロール** 、 **フォーム** です。
