# サインインのブロック
{: .no_toc }

サインインを許可：何も削除せずにユーザーをブロックします
{: .fs-6 .fw-300 }

**サインインを許可** スイッチは、ローカルのユーザーでもディレクトリのユーザーでも、何も削除せずにブロックします。

確認の後でオフにすると、ユーザーのセッションはすぐに終了し、再びオンにするまですべてのサインインが拒否されます。
ユーザーのリストでは、各行のメニューにある **サインインをブロック** と **サインインを許可** で同じことができます。

ユーザー `admin` と、自分自身のサインインはブロックできません。
