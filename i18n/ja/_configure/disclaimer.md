# 免責事項
{: .no_toc }

すべてのユーザーがアプリを使う前に一度同意する規約。誰がどの版にいつ同意したかが記録されます
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

管理者向けです。 **設定 > アクセス > 免責事項** で、ロールオプション `showSettings` を使い、すべてのユーザーに利用規約への同意を求めます。

7.3.0 からは、ページに免責事項のすべての版が表示され、各版はその同意記録とともに専用のページで開きます。
7.2 までは、代わりに三つのタブ（ **全般** 、 **版** 、 **同意記録** ）がありました。アップグレードしてもすべての版は残ります。

## ユーザーに表示されるもの

版が有効な場合、サインインしたすべてのユーザーには、管理者も含め、何よりも先にダイアログでその版が表示されます。

1. タイトルと本文を読みます。
2. チェックボックスをオンにし、 **同意する** をクリックします。赤い **同意しない** を押すと、代わりにサインアウトされます。

7.3.0 からは、ユーザーが応答するまでダイアログの背後のページはぼかして表示されます。

ユーザーは各版に一度だけ同意します。次回のサインインでは再度求められず、求められるのは新しい版が出たとき、
管理者が変更した本文を [全員に再度求める](disclaimer/versions.html#changing-the-text) で保存したとき、または管理者がその同意に対して
[再同意を求める](disclaimer/acceptances.html#asking-users-again) を使ったときだけです。

同意するまでは、API はそのセッションのすべての呼び出しに、ステータス `403` とコード `disclaimer_required` を返します。
ただし、 `/api/v2/disclaimer` と `/api/v2/profile` の下の呼び出しと、ブラウザーが受け取るライブイベントは除きます。
[API トークン](profile/api-token.html) には同意は求められません。スクリプトにはクリックする人がいないためです。
