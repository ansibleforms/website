## リスト

**ユーザー** と **グループ** のリストには、ローカルのユーザーとグループと、その隣に LDAP とシングルサインオンのものが表示されます。

LDAP、Entra ID、OIDC のユーザーやグループは、サインインした（またはサインインで確認された）時点、またはロールがそれを指定した時点で表示されます。
**ソース** 列は、それぞれの取得元を示します：ローカル、LDAP、Microsoft Entra ID、OIDC。7.3.0 からは、 **ユーザー** のリストに
**最終サインイン** 列もあり、各ユーザーが最後にサインインした日時がわかります。

行をクリックすると、そのユーザーまたはグループのページが開きます。 **ユーザーを追加** と **グループを追加** でローカルのものを作成します。

## 管理者権限を与えるアカウント

config.yaml の admin ロールはローカルのグループとユーザーを指定するので、それが指定するアカウントとグループを変更できるのは管理者だけです。

`showSettings` を持ち admin ロールを持たないユーザーは、admin ロールが（直接、またはそのグループのいずれかを通じて）指定するローカルアカウントの
変更、ブロック、グループの変更、パスワードの設定、削除ができません。admin ロールが指定するグループの作成、名前の変更、削除や、
そこへのユーザーの追加もできません。admin ロールに対応付けられる LDAP や SSO のユーザーも同様です。そのブロック、
セッションの終了、削除、API トークンの取り消しは管理者が行います。サーバーはそうしたリクエストに `403` を返します。
