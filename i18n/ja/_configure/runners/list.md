## リスト

**接続 > ランナー** のページには、すべてのランナーが次の列とともに表示されます。

| 列 | 意味 |
|---|---|
| 有効 | ジョブを受け取るかどうか。オフのランナーは、その種類の既定であってもジョブを受け取りません。 |
| 名前 | フォームが `runner: <name>` で参照する名前。 |
| 種類 | RTE、AWX、Ansible Automation Platform、Ascender、Semaphore UI、Rundeck、Jenkins のいずれか。その種類の既定のランナーには、後ろに **既定** のピルが表示されます。 |
| 説明 | 用途。 |

**列** では、既定でオフの列を二つ追加できます。 **モード** は RTE のモード（アウトバウンド、インバウンド、データベース (非推奨)。
[モード](../rte/modes.html) を参照）、 **接続** はソケットモードの RTE へのソケットをアプリノードが持っているかどうかで、 **接続済み** または
**未接続** です。

7.3.0 からは、承認待ちのランナーはリストではなく、その上の通知に表示されます。 [RTE の承認](registration.html#approving-an-rte) を参照してください。
**ランナーを追加** を押すと、ステップ形式のダイアログが開きます。 **ランナー** （名前と説明）、 **種類** 、 **認証情報** で、RTE の場合は **種類** の後に
**モード** のステップ（アウトバウンド（新規の既定）、インバウンド、データベース (非推奨)）があります。RTE では 4 ステップ、ほかの種類では
3 ステップです。 **種類** のステップでは各製品にヒントがあり、RTE のヒントには正式名称 *実行環境* が示されます。行をクリックするとランナーの
ページが開き、行メニューには次のものがあります。

| 操作 | 動作 |
|---|---|
| 編集 | そのページを開きます |
| 接続テスト | 応答し、認証情報を受け入れるかを確認します。 [接続テスト](runner-page.html#test-connection) を参照 |
| 有効にする、無効にする | 現在の状態の逆にオン／オフします |
| 資格情報を変更 | そのページの認証情報タブを開きます |
| 削除 | 削除します |

## 既定と有効

各種類の既定は、その種類のフォームがランナーを指定していないときに実行される場所です。

| 既定の対象 | ランナーを指定していない場合にこれらのフォームが実行される場所 |
|---|---|
| Playbook のフォーム | `ansible` フォーム。RTE で実行 |
| AWX・AAP・Ascender のフォーム | `awx` 、 `aap` 、 `ascender` フォーム。AWX ランナーで実行 |
| Semaphore のフォーム | `semaphore` フォーム |
| Rundeck のフォーム | `rundeck` フォーム |
| Jenkins のフォーム | `jenkins` フォーム |

ある種類の最初のランナーがその種類の既定になるので、種類ごとにランナーが一つだけなら追加の手順は不要です。別のランナーを既定にするには、
そのページの **既定** スイッチをオンにします（ [ランナーのページ](runner-page.html) を参照）。

オフにしたランナーは設定とともにリストに残りますが、その種類の既定であってもジョブは送られません。そのランナー向けのジョブは
*Runner '&lt;name&gt;' is disabled - enable it under Connections > Runners, or name another runner on the form with runner: &lt;name&gt;* で失敗します。
行メニューの **有効にする** または **無効にする** 、あるいはそのページの **有効** スイッチでオン／オフします。新しいランナーはオンで、
7.3.0 より前からあるランナーもアップグレード後はオンです。 [構成シード](../seed/example.html) では `enabled: false` でオフにできます。
