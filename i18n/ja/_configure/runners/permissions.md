# ランナーを管理できるユーザー
{: .no_toc }

ランナーを追加、変更、テストできるユーザー
{: .fs-6 .fw-300 }

ランナーは実行するすべてのジョブの認証情報を受け取るので、ランナーの追加、変更、オン／オフ、削除、そして参加を申請した RTE の承認と拒否は、
**admin** ロールだけが行えます。設定にアクセスできるユーザーはランナーを表示してテストできますが、変更はできません。

[構成シード](../seed/) で宣言されたランナーは、このページでは読み取り専用です。代わりにシードファイルで変更してください。
