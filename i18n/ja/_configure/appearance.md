# 外観
{: .no_toc }

既定値、名前、ロゴ、ブラウザーのアイコン、ヘッダーのリンク、ロゴの横のラベル
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

管理者向けです。 **設定 > 外観** で、ロールオプション `showSettings` を使ってインスタンスの見た目を自社に合わせます。
ロールオプション `showAppearanceSettings` だけでも、ほかの設定は開かずに、お知らせを含むこれらのページを開けます。

このグループのページは **既定値** 、 **名前** 、 **ロゴ** 、 **アイコン** 、 **リンク** 、 **ラベル** 、 **お知らせ** です。
お知らせには専用のページ [お知らせ](announcements.html) があります。保存した既定値、名前、リンク、ラベルは、
開いているすべてのブラウザーにすぐに反映されます。

---

## このセクションの内容

| ページ | 内容 |
|---|---|
| [既定値](appearance/defaults.html) | 何も選んでいないユーザー向けのテーマ、言語、タイムゾーン、日付形式 |
| [名前](appearance/name.html) | ブラウザーのタブとサインインページに表示されるアプリケーション名 |
| [ロゴ](appearance/logo.html) | ヘッダーに表示する独自のロゴ |
| [アイコン](appearance/icon.html) | ブラウザーのタブとブックマークに表示する独自のアイコン |
| [リンク](appearance/links.html) | ヘッダーのリンク（組み込みと独自のもの） |
| [ラベル](appearance/labels.html) | どのインスタンスかを示す、ロゴの横のラベル。7.2 までは環境ラベルが一つだけ |
