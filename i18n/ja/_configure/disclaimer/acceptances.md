# 同意記録
{: .no_toc }

誰がどの版に同意したか、および選んだユーザーへの再同意の要求
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

## 同意したユーザー

各同意はユーザーと版ごとに記録され、版のページの **同意記録** タブに新しい順で表示されます。

| 列 | 意味 |
|---|---|
| **ユーザー** | ユーザー名 |
| **サインイン** | サインインの方法。ローカル、LDAP、Microsoft Entra ID、OpenID Connect |
| **同意日時** | 同意した日時 |
| **IP アドレス** | 同意した場所 |
| **ブラウザー** | 使用したブラウザー |

---

## ユーザーへの再同意の要求

7.3.0 からは、全員に求めることなく、選んだユーザーに版への再同意を求めることができます。

行メニュー、またはリストでチェックした行の **再同意を求める** を使うと、確認の後でそれらの同意が消去されます。対象のユーザーには、
サインインし直さなくても、次のリクエストで免責事項が再び表示されます。リストは、ほかのすべての表と同様にエクスポートすることもできます。

[監査ログ](../production/logs.html#audit-trail) にも、各同意、各拒否、免責事項の各変更が記録されます。
