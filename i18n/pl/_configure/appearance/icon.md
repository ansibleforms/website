# Ikona
{: .no_toc }

Własna ikona na karcie przeglądarki i w zakładkach
{: .fs-6 .fw-300 }

**Ikona** zastępuje ikonę AnsibleForms na karcie przeglądarki i w zakładkach:

| Zasada | Wartość |
|---|---|
| Typy | PNG, ICO, SVG, WEBP, GIF i JPEG |
| Największy plik | 256 KB |
| Najlepszy efekt | Kwadratowy obraz o wymiarach co najmniej 64 × 64 px lub plik SVG |

Wybierz plik w **Nowa ikona** i kliknij **Prześlij**; **Usuń własną ikonę** przywraca ikonę domyślną.
