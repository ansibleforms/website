# Nazwa
{: .no_toc }

Nazwa aplikacji na karcie przeglądarki i na stronie logowania
{: .fs-6 .fw-300 }

**Nazwa** przechowuje **Nazwę aplikacji**, widoczną na karcie przeglądarki i na stronie logowania. Gdy jest pusta, karta przeglądarki pokazuje
`AnsibleForms`, a strona logowania nie pokazuje żadnej nazwy.
