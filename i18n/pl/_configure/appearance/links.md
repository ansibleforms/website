# Linki
{: .no_toc }

Linki nagłówka, wbudowane i własne
{: .fs-6 .fw-300 }

**Linki** ustawiają linki nagłówka dla każdego zalogowanego użytkownika, w dwóch kartach.

**Wbudowane** ma przełącznik **Projektant**, zapisany w [`SHOW_DESIGNER`](../customization/features.html#env_SHOW_DESIGNER) i stosowany
bez restartu. Po wyłączeniu projektant znika dla wszystkich: jego link, strona i API.

**Własne** przechowuje Twoje własne linki, np. do wiki, runbooka lub portalu wsparcia. **Dodaj link** dodaje wiersz z tymi polami:

| Pole | Znaczenie |
|---|---|
| **Ikona** | Ikona przed etykietą, wybrana z listy |
| **Etykieta** | Tekst linku |
| **Adres** | Witryna (`https://…`) lub strona aplikacji (`/forms/all`) |
| **Nowa karta** | Otwiera link w nowej karcie przeglądarki |

Przyciski wiersza go przesuwają: **→** umieszcza link wewnątrz linku powyżej, który wtedy otwiera się w nagłówku jako menu,
**←** wyjmuje go z powrotem do nagłówka, a strzałki w górę i w dół go przesuwają (menu razem z linkami w środku).
Menu nie potrzebuje własnego adresu.

Nagłówek mieści najwyżej 5 Twoich linków po wbudowanych i najwyżej 10 wewnątrz każdego menu.
