# Kto zarządza runnerami
{: .no_toc }

Kto może dodawać, zmieniać i testować runnery
{: .fs-6 .fw-300 }

Runner otrzymuje poświadczenia każdego zadania, które uruchamia, więc tylko rola **admin** dodaje, zmienia, włącza, wyłącza i usuwa runnery
oraz zatwierdza lub odrzuca RTE, które poprosiło o dołączenie. Użytkownicy z dostępem do ustawień je widzą i mogą je testować, ale nie mogą ich zmieniać.

Runner zadeklarowany w [config seed](../seed/) jest na tej stronie tylko do odczytu: zmień go zamiast tego w pliku seed.
