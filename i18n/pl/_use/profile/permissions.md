# Uprawnienia
{: .no_toc }

Co pozwalają ci robić twoje role
{: .fs-6 .fw-300 }

---

Opcje ról są pogrupowane w karty, a każda karta pokazuje, ile jej opcji masz, np. `5/8`:

| Karta | Opcje dotyczące |
|---|---|
| **Dostęp i integracje** | Logowania, asystenta czatu, serwera MCP, przesyłania plików i tokenów API |
| **Projektant** | Otwierania projektanta oraz edycji formularzy, playbooków, workflowów, inwentarzy i plików zmiennych |
| **Zadania** | Wyświetlania zadań i ich extravars lub artefaktów, ponownego uruchamiania, usuwania, planowania i zapisywania zadań |
| **Ustawienia** | Stron ustawień, logów, dziennika audytu i kopii zapasowych |
| **Inne** | Opcja ustawiona w roli ręcznie, która nie należy do żadnej innej karty; zawsze ostatnia karta |

Pozostałe karty są w kolejności alfabetycznej. Każda karta to tabela z kolumnami **Ustawienie** (opcja), **Opis**
(co robi) i **Twój dostęp**: **Dozwolone** lub **Niedozwolone**. Opcja, która obowiązuje z powodu innej, informuje o tym
pod swoim opisem: **Zawarte w** opcji, którą masz, włącza ją, a **Wymaga** opcji, której nie masz, utrzymuje ją wyłączoną.

Opcje pochodzą z `options` twoich ról w `config.yaml`; strona [Role](../config/roles.html) wyjaśnia, jak
się łączą.
