# Konto
{: .no_toc }

Jako kto jesteś zalogowany
{: .fs-6 .fw-300 }

---

Widok Konto pokazuje, jako kto jesteś zalogowany i co decyduje o twoim dostępie:

- **Nazwa użytkownika** i **Typ logowania**: konto lokalne, LDAP, Microsoft Entra ID lub OpenID Connect.
- **Grupy**: grupy, które przychodzą z twoim logowaniem, takie jak `local/admins` czy `ldap/Domain Admins`.
- **Role**: role z `config.yaml` pasujące do tych grup i do twojego użytkownika. Decydują one o tym,
  które formularze widzisz i jakie masz opcje.
