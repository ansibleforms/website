# Ankündigungen
{: .no_toc }

Nachrichten unter der Kopfzeile für alle, etwa ein Wartungsfenster, jede von ihrem Beginn bis zu ihrem Ende
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

Für Administratoren: Informieren Sie alle Benutzer über ein Wartungsfenster oder eine Störung, unter **Einstellungen > Erscheinungsbild > Ankündigungen**.

Die Seite benötigt die Rollenoption `showSettings` oder `showAppearanceSettings`. Ab 7.3.0 ist es eine einzige Liste, und jede Ankündigung
hat ihre eigene Seite und ihren eigenen Schalter Aktiviert.

## Wo sie erscheinen

Ankündigungen erscheinen als Zeile unter der Kopfzeile jeder Seite, für jeden angemeldeten Benutzer, jede in der Farbe ihres Typs.

Mehrere aktivierte können gleichzeitig erscheinen, die neueste zuerst. Die Anmeldeseite und ein in eine andere Website eingebettetes Formular zeigen keine.

Jede hat eine Schließen-Schaltfläche. Eine geschlossene Ankündigung bleibt in diesem Browser-Tab geschlossen, bis der Tab geschlossen wird oder
bis sich ihre Nachricht oder ihr Enddatum ändert. Eine gespeicherte Ankündigung erreicht sofort jeden geöffneten Browser; eine, die
ihr Start- oder Enddatum erreicht, wird dort innerhalb einer Minute ein- oder ausgeblendet.
