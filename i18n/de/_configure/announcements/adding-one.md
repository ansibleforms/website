# Eine hinzufügen
{: .no_toc }

Der Assistent in zwei Schritten: die Nachricht, dann wann sie erscheint
{: .fs-6 .fw-300 }

**Ankündigung hinzufügen** öffnet einen Assistenten in zwei Schritten. **Nachricht** fragt, was sie sagt:

| Feld | Bedeutung |
|---|---|
| **Nachricht** | Der Text, höchstens 500 Zeichen. Erforderlich. |
| **Typ** | Ihre Farbe und ihr Symbol: blau für Info (der Standard), gelb für Warnung, rot für Gefahr |

**Wann** fragt, wann sie erscheint:

| Feld | Bedeutung |
|---|---|
| **Startdatum** | Sie erscheint ab diesem Moment. Leer lassen, um sie sofort anzuzeigen. |
| **Enddatum** | Zu diesem Moment wird sie ausgeblendet und gelöscht. Leer lassen, um sie zu behalten, bis Sie sie löschen. |

Das Enddatum muss nach dem Startdatum und in der Zukunft liegen.
