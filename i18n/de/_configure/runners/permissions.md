# Wer Runner verwaltet
{: .no_toc }

Wer Runner hinzufügen, ändern und testen darf
{: .fs-6 .fw-300 }

Ein Runner erhält die Anmeldedaten jedes Jobs, den er ausführt, daher fügt nur die Rolle **admin** Runner hinzu, ändert sie, schaltet sie ein oder aus und löscht sie,
und gibt eine RTE, die um Beitritt gebeten hat, frei oder lehnt sie ab. Benutzer mit Zugriff auf die Einstellungen sehen sie und können sie testen, aber nicht ändern.

Ein im [Config-Seed](../seed/) deklarierter Runner ist auf dieser Seite schreibgeschützt: Ändern Sie ihn stattdessen in der Seed-Datei.
