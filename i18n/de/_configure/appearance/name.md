# Name
{: .no_toc }

Der Anwendungsname im Browser-Tab und auf der Anmeldeseite
{: .fs-6 .fw-300 }

**Name** enthält den **Anwendungsnamen**, angezeigt im Browser-Tab und auf der Anmeldeseite. Ist er leer, zeigt der Browser-Tab
`AnsibleForms` und die Anmeldeseite keinen Namen.
