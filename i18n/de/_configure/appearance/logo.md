# Logo
{: .no_toc }

Ihr eigenes Logo in der Kopfzeile
{: .fs-6 .fw-300 }

**Logo** ersetzt das AnsibleForms-Logo in der Kopfzeile durch Ihr eigenes Bild, das in jedem Design angezeigt wird:

| Regel | Wert |
|---|---|
| Typen | PNG, JPEG, WEBP, GIF und SVG |
| Größte Datei | 900 KB |
| Größe in der Kopfzeile | Höchstens 200 × 33 px, mit beibehaltenen Proportionen |

Wählen Sie unter **Neues Logo** eine Datei aus, um eine Vorschau zu sehen, und klicken Sie dann auf **Hochladen**. **Aktuelles Logo** zeigt das verwendete Logo und die Größe,
in der die Kopfzeile es anzeigt. **Eigenes Logo entfernen** stellt das Standardlogo wieder her, das dem Design folgt.
