# Symbol
{: .no_toc }

Ihr eigenes Symbol im Browser-Tab und in Lesezeichen
{: .fs-6 .fw-300 }

**Symbol** ersetzt das Symbol von AnsibleForms im Browser-Tab und in Lesezeichen:

| Regel | Wert |
|---|---|
| Typen | PNG, ICO, SVG, WEBP, GIF und JPEG |
| Größte Datei | 256 KB |
| Bestes Ergebnis | Ein quadratisches Bild von mindestens 64 × 64 px oder ein SVG |

Wählen Sie unter **Neues Symbol** eine Datei aus und klicken Sie auf **Hochladen**; **Eigenes Symbol entfernen** stellt das Standardsymbol wieder her.
