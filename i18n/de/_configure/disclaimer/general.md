## Die Liste

Ab 7.3.0 ist **Einstellungen > Zugriff > Haftungsausschluss** eine Liste der Versionen des Haftungsausschlusses, eine pro Text, so wie ihm zugestimmt wurde:

| Spalte | Bedeutung |
|---|---|
| **Aktiviert** | Ob dies die Version ist, die Benutzer akzeptieren; höchstens eine ist aktiviert |
| **Version** | Ihre Nummer, ab 1 hochgezählt |
| **Titel** | Der Titel ihres Dialogs |
| **Veröffentlicht von** | Wer sie hinzugefügt hat |
| **Veröffentlicht** | Wann |
| **Zustimmungen** | Wie viele Benutzer sie akzeptiert haben |

Ein Klick auf eine Zeile oder **Bearbeiten** im Menü der Zeile öffnet die [Seite der Version](versions.html). Das Menü enthält außerdem **Aktivieren** oder **Deaktivieren** sowie **Löschen**.

---

## Eine Version hinzufügen

**Hinweis hinzufügen** öffnet einen Dialog für eine neue Version mit der nächsten Nummer, die erst aktiviert ist, wenn Sie sie aktivieren:

| Feld | Bedeutung |
|---|---|
| **Titel** | Der Titel des Dialogs, etwa Nutzungsbedingungen |
| **Text** | Das, dem Benutzer zustimmen, höchstens 20000 Zeichen. Reiner Text: Zeilenumbrüche bleiben erhalten. |
| **Kontrollkästchen** | Was Benutzer anhaken, bevor sie akzeptieren können, anfangs „Ich habe diese Bedingungen gelesen und stimme ihnen zu.“ |

Alle drei sind erforderlich. Die bis dahin aktivierte Version bleibt die, die Benutzer akzeptieren, sodass sich ein neuer Text im Voraus vorbereiten lässt.

---

## Eine Version aktivieren

**Aktivieren** im Menü einer Zeile oder der Schalter **Aktiviert** auf der Seite der Version macht diese Version zu der, die Benutzer akzeptieren, und schaltet die
anderen aus.

Benutzer, die diese Version bereits akzeptiert haben, werden nicht erneut gefragt, sodass sich eine frühere Version wieder aktivieren lässt, ohne alle zu fragen.
**Deaktivieren** auf der aktivierten Version schaltet den Haftungsausschluss aus, bis wieder eine Version aktiviert wird; die Versionen und Zustimmungen bleiben erhalten.
Das Löschen einer Version löscht auch ihre Zustimmungen, und das Löschen der aktivierten schaltet den Haftungsausschluss aus.
