# Mehrere Gruppen
{: .no_toc }

Ein lokaler Benutzer in mehreren Gruppen und seine Rollen
{: .fs-6 .fw-300 }

Ein lokaler Benutzer kann mehreren Gruppen angehören und erhält die Rollen jeder davon: Rollen nennen eine Gruppe als `local/<group>`.

Im Tab **Gruppen** fügt **Gruppe hinzufügen** den Benutzer einer weiteren Gruppe hinzu, und das Menü einer Zeile oder die Kontrollkästchen entfernen eine.
Ein Benutzer behält mindestens eine Gruppe. Die Benutzerliste hat dafür **Zu Gruppe hinzufügen** im Menü jeder Zeile.
