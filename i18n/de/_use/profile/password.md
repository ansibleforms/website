# Passwort
{: .no_toc }

Das Passwort eines lokalen Kontos ändern
{: .fs-6 .fw-300 }

---

Geben Sie Ihr aktuelles Passwort und zweimal das neue ein, und klicken Sie dann auf **Passwort ändern**.

Konten von LDAP, Entra ID und OpenID Connect ändern ihr Passwort stattdessen bei diesem Anbieter.
