# Rundgang durch die Oberfläche
{: .no_toc }

Ein bebilderter Rundgang durch die Weboberfläche von AnsibleForms, vom Dashboard bis zu den fortgeschrittenen Administrationsfunktionen.
{: .fs-6 .fw-300 }

---

Für alle Benutzer und Administratoren: die Bildschirme der Weboberfläche, gruppiert nach dem, was Sie damit tun.

---

## In diesem Abschnitt

Jede Gruppe von Bildschirmen hat eine eigene Seite:

| Seite | Was sie behandelt |
|---|---|
| [Formulare und Jobs](forms-and-jobs.html) | Die Anmeldung, das Dashboard, das Ausfüllen eines Formulars und das Verfolgen seiner Jobs |
| [Designer und Git](designer-and-git.html) | Formulare bearbeiten und in Git aufbewahren |
| [Administration](administration.html) | Das Menü Einstellungen: das System, sein Erscheinungsbild, Zugriff, Verbindungen und Protokolle |
| [Persönliche Einstellungen](personal-settings.html) | Ihr Profil und das dunkle Theme |
