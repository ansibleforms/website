## Beispiel

Ein mehrstufiges Formular führt mehrere Jobs nacheinander aus, wobei jeder Schritt sein eigenes Playbook oder seine eigene AWX-Vorlage startet. Alle Schritte teilen sich die Felder des Formulars: Standardmäßig erhält jeder Schritt die vollständigen Extravars, und der `key` eines Schritts beschränkt ihn auf diesen Teil davon.

### Einen Server erstellen und konfigurieren

Jeder Schritt erhält seinen eigenen Teil der Extravars: Ein AWX-Schritt erstellt den Server, ein Ansible-Schritt konfiguriert sein Netzwerk, und ein letzter Schritt sendet immer einen Bericht:

```yaml
name: Server Provisioning
type: multistep
roles:
  - default
categories:
  - Setup
steps:
  - name: Create server
    type: awx
    template: Create VM
    key: server              # receives only the `server` part of the extravars
  - name: Configure network
    type: ansible
    playbook: configure_network.yml
    key: network             # receives only the `network` part of the extravars
  - name: Send report
    type: ansible
    playbook: email.yml
    always: true             # runs even when an earlier step failed
fields:
  - name: server_name
    type: text
    model: server.name
  - name: environment
    type: enum
    values:
      - dev
      - prod
    model: server.environment
  - name: ip_address
    type: text
    model: network.ip
  - name: gateway
    type: text
    model: network.gateway
```
