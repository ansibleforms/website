## Über `__parent__` auf Daten des übergeordneten Formulars zugreifen

Wenn ein `yaml`-Feld den Modus `subform` verwendet, fügt AnsibleForms eine Variable `__parent__` in das Unterformular ein. Sie enthält eine Momentaufnahme **aller Feldwerte des übergeordneten Formulars** zum Zeitpunkt, an dem sich der Editor öffnet, einschließlich Konstanten und Vars.

Verweisen Sie darauf mit der üblichen Ausdruckssyntax `$(...)` in den Felddefinitionen des Unterformulars:

```yaml
- name: NetworkConfig
  type: subform
  fields:
    - name: interface
      type: text
      label: Interface
      required: true

    - name: vlan
      type: enum
      label: VLAN
      # filter available VLANs based on the parent's selected region
      query: "select id,name from vlans where region='$(__parent__.region)'"
      dbConfig:
        name: MYDB
        type: mysql
      valueColumn: id
      placeholderColumn: name

    - name: mtu
      type: number
      label: MTU
      # default to 9000 in production, 1500 elsewhere
      default: "'$(__parent__.environment)' === 'production' ? 9000 : 1500"
      evalDefault: true

- name: Configure server
  type: ansible
  playbook: configure.yml
  roles: [default]
  fields:
    - name: environment
      type: enum
      values: [dev, staging, production]

    - name: region
      type: enum
      values: [eu-west-1, us-east-1, ap-southeast-1]

    - name: nic
      type: yaml
      label: Network interface
      subform: NetworkConfig
```

{: .note }
> `__parent__` ist ein Hilfsmittel **nur für das Frontend**. Es wird aus den Ansible-Extravars entfernt und nie an das Playbook gesendet.
