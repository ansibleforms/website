# Nome
{: .no_toc }

Il nome dell'applicazione nella scheda del browser e nella pagina di accesso
{: .fs-6 .fw-300 }

**Nome** contiene il **Nome dell'applicazione**, mostrato nella scheda del browser e nella pagina di accesso. Se è vuoto, la scheda del browser mostra
`AnsibleForms` e la pagina di accesso non mostra alcun nome.
