# Icona
{: .no_toc }

La tua icona nella scheda del browser e nei segnalibri
{: .fs-6 .fw-300 }

**Icona** sostituisce l'icona di AnsibleForms nella scheda del browser e nei segnalibri:

| Regola | Valore |
|---|---|
| Tipi | PNG, ICO, SVG, WEBP, GIF e JPEG |
| File più grande | 256 KB |
| Risultato migliore | Un'immagine quadrata di almeno 64 × 64 px, oppure un SVG |

Scegli un file in **Nuova icona** e fai clic su **Carica**; **Rimuovi l'icona personalizzata** ripristina l'icona predefinita.
