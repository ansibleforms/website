# Logo
{: .no_toc }

Il tuo logo nell'intestazione
{: .fs-6 .fw-300 }

**Logo** sostituisce il logo di AnsibleForms nell'intestazione con la tua immagine, mostrata in ogni tema:

| Regola | Valore |
|---|---|
| Tipi | PNG, JPEG, WEBP, GIF e SVG |
| File più grande | 900 KB |
| Dimensione nell'intestazione | Al massimo 200 × 33 px, mantenendo le proporzioni |

Scegli un file in **Nuovo logo** per vederne l'anteprima, poi fai clic su **Carica**. **Logo attuale** mostra il logo in uso e la dimensione
con cui lo mostra l'intestazione. **Rimuovi logo personalizzato** ripristina il logo predefinito, che segue il tema.
