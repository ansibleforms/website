# Più gruppi
{: .no_toc }

Un utente locale in più gruppi, e i loro ruoli
{: .fs-6 .fw-300 }

Un utente locale può appartenere a più gruppi, e riceve i ruoli di ciascuno di essi: i ruoli indicano un gruppo come `local/<group>`.

Nella scheda **Gruppi**, **Aggiungi gruppo** aggiunge l'utente a un altro gruppo, e il menu di una riga o le caselle di spunta ne rimuovono uno.
Un utente conserva almeno un gruppo. La lista degli utenti ha **Aggiungi a un gruppo** nel menu di ogni riga per fare lo stesso.
