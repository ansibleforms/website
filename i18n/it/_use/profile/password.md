# Password
{: .no_toc }

Cambiare la password di un account locale
{: .fs-6 .fw-300 }

---

Inserisci la password attuale e quella nuova due volte, poi fai clic su **Cambia password**.

Gli account LDAP, Entra ID e OpenID Connect cambiano invece la password presso quel provider.
