# Wachtwoord
{: .no_toc }

Het wachtwoord van een lokaal account wijzigen
{: .fs-6 .fw-300 }

---

Voer je huidige wachtwoord in en twee keer het nieuwe, en klik dan op **Wachtwoord wijzigen**.

Accounts van LDAP, Entra ID en OpenID Connect wijzigen hun wachtwoord in plaats daarvan bij die provider.
