## Voorbeeld

Een multistep-formulier voert meerdere jobs na elkaar uit, waarbij elke stap zijn eigen playbook of AWX-sjabloon start. Alle stappen delen de velden van het formulier: standaard krijgt elke stap de volledige extravars, en de `key` van een stap beperkt die tot dat deel ervan.

### Een server aanmaken en configureren

Elke stap krijgt zijn eigen deel van de extravars: een AWX-stap maakt de server aan, een Ansible-stap configureert het netwerk, en een laatste stap stuurt altijd een rapport:

```yaml
name: Server Provisioning
type: multistep
roles:
  - default
categories:
  - Setup
steps:
  - name: Create server
    type: awx
    template: Create VM
    key: server              # receives only the `server` part of the extravars
  - name: Configure network
    type: ansible
    playbook: configure_network.yml
    key: network             # receives only the `network` part of the extravars
  - name: Send report
    type: ansible
    playbook: email.yml
    always: true             # runs even when an earlier step failed
fields:
  - name: server_name
    type: text
    model: server.name
  - name: environment
    type: enum
    values:
      - dev
      - prod
    model: server.environment
  - name: ip_address
    type: text
    model: network.ip
  - name: gateway
    type: text
    model: network.gateway
```
