# Een kanaal testen
{: .no_toc }

Test versturen, en wat het bewijst
{: .fs-6 .fw-300 }

**Test versturen** stuurt een testmelding via het kanaal zoals het is opgeslagen, dus sla je wijzigingen eerst op. Het werkt ook op een kanaal
dat is uitgeschakeld. Voor een mailkanaal
vraagt het dialoogvenster naar welk adres er moet worden verstuurd; de andere posten in hun eigen kanaal. Het dialoogvenster toont of het werkte,
en de reden als het niet werkte.
