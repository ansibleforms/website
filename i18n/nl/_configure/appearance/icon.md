# Pictogram
{: .no_toc }

Je eigen pictogram in het browsertabblad en in bladwijzers
{: .fs-6 .fw-300 }

**Pictogram** vervangt het pictogram van AnsibleForms in het browsertabblad en in bladwijzers:

| Regel | Waarde |
|---|---|
| Typen | PNG, ICO, SVG, WEBP, GIF en JPEG |
| Grootste bestand | 256 KB |
| Beste resultaat | Een vierkante afbeelding van minstens 64 × 64 px, of een SVG |

Kies een bestand onder **Nieuw pictogram** en klik op **Uploaden**; **Eigen pictogram verwijderen** zet het standaardpictogram terug.
