# Tester un canal
{: .no_toc }

Envoyer un test, et ce que cela prouve
{: .fs-6 .fw-300 }

**Envoyer un test** envoie une notification de test via le canal tel qu'il est enregistré, enregistrez donc d'abord vos modifications. Cela fonctionne aussi sur un canal
désactivé. Pour un canal mail,
la boîte de dialogue demande l'adresse de destination ; les autres publient dans leur propre canal. La boîte de dialogue indique si cela a fonctionné,
et la raison dans le cas contraire.
