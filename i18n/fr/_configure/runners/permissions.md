# Qui gère les runners
{: .no_toc }

Qui peut ajouter, modifier et tester des runners
{: .fs-6 .fw-300 }

Un runner reçoit les identifiants de chaque job qu'il exécute, c'est pourquoi seul le rôle **admin** ajoute, modifie, active ou désactive et supprime des runners,
et approuve ou refuse un RTE qui a demandé à rejoindre. Les utilisateurs ayant accès aux paramètres les voient et peuvent les tester, mais pas les modifier.

Un runner déclaré dans le [seed de configuration](../seed/) est en lecture seule sur cette page : modifiez-le plutôt dans le fichier seed.
