# Apparence
{: .no_toc }

Les valeurs par défaut, le nom, le logo, l'icône du navigateur, les liens de l'en-tête et les étiquettes à côté du logo
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

Pour les administrateurs : donnez à l'instance votre image, dans **Paramètres > Apparence**, avec l'option de rôle `showSettings`.
L'option de rôle `showAppearanceSettings` seule ouvre aussi ces pages, annonces comprises, sans le reste des paramètres.

Les pages de ce groupe sont **Valeurs par défaut**, **Nom**, **Logo**, **Icône**, **Liens**, **Étiquettes** et **Annonces** ;
les annonces ont leur propre page, [Annonces](announcements.html). Une valeur par défaut, un nom, un lien ou une étiquette enregistrés
s'affichent immédiatement dans tous les navigateurs ouverts.
