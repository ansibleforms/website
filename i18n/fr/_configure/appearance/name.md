# Nom
{: .no_toc }

Le nom de l'application dans l'onglet du navigateur et sur la page de connexion
{: .fs-6 .fw-300 }

**Nom** contient le **Nom de l'application**, affiché dans l'onglet du navigateur et sur la page de connexion. Vide, l'onglet du navigateur affiche
`AnsibleForms` et la page de connexion n'affiche aucun nom.
