# Logo
{: .no_toc }

Votre propre logo dans l'en-tête
{: .fs-6 .fw-300 }

**Logo** remplace le logo d'AnsibleForms dans l'en-tête par votre propre image, affichée dans tous les thèmes :

| Règle | Valeur |
|---|---|
| Types | PNG, JPEG, WEBP, GIF et SVG |
| Taille maximale du fichier | 900 Ko |
| Taille dans l'en-tête | Au plus 200 × 33 px, proportions conservées |

Choisissez un fichier sous **Nouveau logo** pour l'apercevoir, puis cliquez sur **Télécharger**. **Logo actuel** montre le logo utilisé et la taille
à laquelle l'en-tête l'affiche. **Supprimer le logo personnalisé** rétablit le logo par défaut, qui suit le thème.
