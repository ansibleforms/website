# Icône
{: .no_toc }

Votre propre icône dans l'onglet du navigateur et dans les favoris
{: .fs-6 .fw-300 }

**Icône** remplace l'icône d'AnsibleForms dans l'onglet du navigateur et dans les favoris :

| Règle | Valeur |
|---|---|
| Types | PNG, ICO, SVG, WEBP, GIF et JPEG |
| Taille maximale du fichier | 256 Ko |
| Meilleur résultat | Une image carrée d'au moins 64 × 64 px, ou un SVG |

Choisissez un fichier sous **Nouvelle icône** et cliquez sur **Téléverser** ; **Supprimer l'icône personnalisée** rétablit l'icône par défaut.
