# Plusieurs groupes
{: .no_toc }

Un utilisateur local dans plusieurs groupes, et ses rôles
{: .fs-6 .fw-300 }

Un utilisateur local peut appartenir à plusieurs groupes, et reçoit les rôles de chacun d'eux : les rôles nomment un groupe `local/<group>`.

Dans l'onglet **Groupes**, **Ajouter un groupe** ajoute l'utilisateur à un autre groupe, et le menu d'une ligne ou les cases à cocher en retirent un.
Un utilisateur garde au moins un groupe. La liste des utilisateurs propose **Ajouter à un groupe** dans le menu de chaque ligne pour la même chose.
