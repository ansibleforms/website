# Bloquer une connexion
{: .no_toc }

Autoriser la connexion : bloquer un utilisateur sans rien supprimer
{: .fs-6 .fw-300 }

L'interrupteur **Autoriser la connexion** bloque un utilisateur, local ou issu d'un annuaire, sans rien supprimer.

Une fois désactivé, après une confirmation, les sessions de l'utilisateur se terminent immédiatement et toute connexion est refusée jusqu'à ce que vous le réactiviez.
La liste des utilisateurs propose **Bloquer la connexion** et **Autoriser la connexion** dans le menu de chaque ligne pour la même chose.

Vous ne pouvez bloquer ni l'utilisateur `admin`, ni votre propre connexion.
