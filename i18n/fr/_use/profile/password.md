# Mot de passe
{: .no_toc }

Changer le mot de passe d'un compte local
{: .fs-6 .fw-300 }

---

Saisissez votre mot de passe actuel et deux fois le nouveau, puis cliquez sur **Changer le mot de passe**.

Les comptes LDAP, Entra ID et OpenID Connect changent plutôt leur mot de passe auprès de ce fournisseur.
