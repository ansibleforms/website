# Compte
{: .no_toc }

Avec quel compte vous êtes connecté
{: .fs-6 .fw-300 }

---

La vue Compte montre avec quel compte vous êtes connecté et ce qui détermine votre accès :

- **Nom d'utilisateur** et **Type de connexion** : un compte local, LDAP, Microsoft Entra ID ou OpenID Connect.
- **Groupes** : les groupes fournis avec votre connexion, comme `local/admins` ou `ldap/Domain Admins`.
- **Rôles** : les rôles de `config.yaml` qui correspondent à ces groupes et à votre utilisateur. Ils déterminent
  quels formulaires vous voyez et de quelles options vous disposez.
