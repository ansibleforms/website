# Diversos grups
{: .no_toc }

Un usuari local en diversos grups, i els seus rols
{: .fs-6 .fw-300 }

Un usuari local pot pertànyer a diversos grups, i rep els rols de tots ells: els rols nomenen un grup com a `local/<group>`.

A la pestanya **Grups**, **Afegeix un grup** afegeix l'usuari a un altre grup, i el menú d'una fila o les caselles en treuen un.
Un usuari conserva almenys un grup. La llista d'usuaris té **Afegeix a un grup** al menú de cada fila per fer el mateix.
