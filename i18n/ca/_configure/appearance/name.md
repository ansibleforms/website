# Nom
{: .no_toc }

El nom de l'aplicació a la pestanya del navegador i a la pàgina d'inici de sessió
{: .fs-6 .fw-300 }

**Nom** conté el **Nom de l'aplicació**, que es mostra a la pestanya del navegador i a la pàgina d'inici de sessió. Si és buit, la pestanya del navegador mostra
`AnsibleForms` i la pàgina d'inici de sessió no mostra cap nom.
