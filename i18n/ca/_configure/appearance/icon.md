# Icona
{: .no_toc }

La teva pròpia icona a la pestanya del navegador i a les adreces d'interès
{: .fs-6 .fw-300 }

**Icona** substitueix la icona d'AnsibleForms a la pestanya del navegador i a les adreces d'interès:

| Regla | Valor |
|---|---|
| Tipus | PNG, ICO, SVG, WEBP, GIF i JPEG |
| Mida màxima | 256 KB |
| Millor resultat | Una imatge quadrada d'almenys 64 × 64 px, o un SVG |

Tria un fitxer a **Icona nova** i fes clic a **Puja**; **Elimina la icona personalitzada** recupera la icona predeterminada.
