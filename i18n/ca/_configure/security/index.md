# Seguretat
{: .no_toc }

Protegeix una instància: el compte d'admin, els seus secrets, HTTPS i què poden fer els usuaris i els formularis
{: .fs-6 .fw-300 }

---

Per a administradors que preparen una instància per a producció, i per a revisions de seguretat d'una instància existent.

---

## En aquesta secció

Cada tema té la seva pròpia pàgina:

| Pàgina | Què hi trobaràs |
|---|---|
| [Enduriment](hardening.html) | El compte d'admin, els límits d'inici de sessió, la base de dades, les expressions, les dades de les tasques, la política del navegador, les funcions opcionals i les opcions de rol |
| [HTTPS](https.html) | On acaba el TLS, servir HTTPS des de l'aplicació, i substituir el certificat d'exemple |
| [Secrets i xifratge](secrets.html) | `ENCRYPTION_SECRET`, `ACCESS_TOKEN_SECRET`, i la durada dels tokens |

Pàgines relacionades: [Autenticació](../authentication/) per als mètodes d'inici de sessió, [Validació del llançament](../launch-validation/) per a les
comprovacions al servidor de cada llançament, i les [Variables de seguretat](../customization/security.html).
