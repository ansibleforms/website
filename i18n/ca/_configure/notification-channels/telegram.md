# Telegram
{: .no_toc }

Un bot que publica en un xat de Telegram
{: .fs-6 .fw-300 }

Un canal de Telegram és un bot que publica en un xat. El seu pas **Credencials** conté el **Token del bot**, i el seu pas **Bot**, la resta:

| Camp | Significat |
|---|---|
| Token del bot | Una credencial **api** de [Connexions > Credencials](../credentials.html) la contrasenya de la qual és el token del bot que dona BotFather. |
| Id del xat | El xat, el grup o el canal on publica el bot; un nombre negatiu per a un grup o un canal. |
| Adreça de la Bot API | Un servidor Bot API propi; buit per a `api.telegram.org`. |
