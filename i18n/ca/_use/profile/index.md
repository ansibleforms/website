# El teu perfil
{: .no_toc }

El teu compte, les preferències, la contrasenya, els permisos i els tokens d'API
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

Per a tots els usuaris: el teu propi compte, les preferències, la contrasenya, els permisos i els tokens d'API.

Obre el teu perfil des de l'avatar de la part superior dreta: **Perfil**.

---

## Obrir una vista

El menú de l'esquerra mostra les vistes del perfil per ordre alfabètic. Cada vista té la seva pròpia adreça,
de manera que hi pots enllaçar directament:

| Vista | Adreça |
|---|---|
| Compte | `/profile/account` |
| Tokens d'API | `/profile/token` |
| Contrasenya | `/profile/password` |
| Permisos | `/profile/permissions` |
| Preferències | `/profile/preferences` |

`/profile` sol obre la primera vista del menú. Les vistes que els teus rols no permeten estan amagades; la seva adreça obre la primera
vista. **Tokens d'API** només es mostra quan un dels teus rols té l'opció de rol `allowApiTokens`.
