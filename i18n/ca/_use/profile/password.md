# Contrasenya
{: .no_toc }

Canvia la contrasenya d'un compte local
{: .fs-6 .fw-300 }

---

Introdueix la teva contrasenya actual i la nova dues vegades, i després fes clic a **Canvia la contrasenya**.

Els comptes d'LDAP, Entra ID i OpenID Connect canvien la contrasenya amb el seu proveïdor.
