# Compte
{: .no_toc }

Amb quin usuari has iniciat la sessió
{: .fs-6 .fw-300 }

---

La vista Compte mostra amb quin usuari has iniciat la sessió i què determina el teu accés:

- **Nom d'usuari** i **Tipus d'inici de sessió**: un compte local, LDAP, Microsoft Entra ID o OpenID Connect.
- **Grups**: els grups que vénen amb el teu inici de sessió, com ara `local/admins` o `ldap/Domain Admins`.
- **Rols**: els rols de `config.yaml` que coincideixen amb aquests grups i amb el teu usuari. Determinen
  quins formularis veus i quines opcions tens.
