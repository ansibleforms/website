# Nombre
{: .no_toc }

El nombre de la aplicación en la pestaña del navegador y en la página de inicio de sesión
{: .fs-6 .fw-300 }

**Nombre** contiene el **Nombre de la aplicación**, mostrado en la pestaña del navegador y en la página de inicio de sesión. Vacío, la pestaña del navegador muestra
`AnsibleForms` y la página de inicio de sesión no muestra ningún nombre.
