# Añadir uno
{: .no_toc }

El asistente de dos pasos: el mensaje y, después, cuándo se muestra
{: .fs-6 .fw-300 }

**Añadir anuncio** abre un asistente de dos pasos. **Mensaje** pregunta qué dice:

| Campo | Significado |
|---|---|
| **Mensaje** | El texto, como máximo 500 caracteres. Obligatorio. |
| **Tipo** | Su color y su icono: azul para Información (el predeterminado), ámbar para Advertencia, rojo para Peligro |

**Cuándo** pregunta cuándo se muestra:

| Campo | Significado |
|---|---|
| **Fecha de inicio** | Se muestra a partir de este momento. Déjala vacía para mostrarlo de inmediato. |
| **Fecha de fin** | En este momento se oculta y se elimina. Déjala vacía para mantenerlo hasta que lo elimines. |

La fecha de fin debe ser posterior a la fecha de inicio y estar en el futuro.
