# Varios grupos
{: .no_toc }

Un usuario local en varios grupos, y sus roles
{: .fs-6 .fw-300 }

Un usuario local puede pertenecer a varios grupos, y recibe los roles de todos ellos: los roles nombran un grupo como `local/<group>`.

En la pestaña **Grupos**, **Agregar grupo** añade al usuario a otro grupo, y el menú de una fila o las casillas quitan uno.
Un usuario conserva al menos un grupo. La lista de usuarios tiene **Añadir a un grupo** en el menú de cada fila para lo mismo.
