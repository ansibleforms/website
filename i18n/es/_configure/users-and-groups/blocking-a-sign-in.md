# Bloquear un inicio de sesión
{: .no_toc }

Permitir inicio de sesión: bloquea a un usuario sin eliminar nada
{: .fs-6 .fw-300 }

El interruptor **Permitir inicio de sesión** bloquea a un usuario, local o de un directorio, sin eliminar nada.

Al desactivarlo, tras una confirmación, las sesiones del usuario terminan al instante y se rechaza cada inicio de sesión hasta que vuelvas a activarlo.
La lista de usuarios tiene **Bloquear inicio de sesión** y **Permitir inicio de sesión** en el menú de cada fila para lo mismo.

No puedes bloquear al usuario `admin`, ni tu propio inicio de sesión.
