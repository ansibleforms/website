# Contraseña
{: .no_toc }

Cambia la contraseña de una cuenta local
{: .fs-6 .fw-300 }

---

Introduce tu contraseña actual y la nueva dos veces, y haz clic en **Cambiar contraseña**.

Las cuentas LDAP, Entra ID y OpenID Connect cambian su contraseña en ese proveedor.
