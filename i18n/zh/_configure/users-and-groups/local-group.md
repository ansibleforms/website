# 本地组
{: .no_toc }

本地组的页面及其选项卡
{: .fs-6 .fw-300 }

组的页面 `/settings/groups/<id>` 包含以下选项卡：

| 选项卡 | 显示的内容 |
|---|---|
| **详情** | 名称和描述 |
| **用户** | 组中的用户；**添加用户** 添加一个用户，行菜单或复选框用于移除用户 |
| **角色** | 引用该组的角色 |
| **表单** | 这些角色可以打开的表单 |

仍有用户的组不能删除：请先移除其中的用户。`admins` 组永远不能被删除或重命名。
