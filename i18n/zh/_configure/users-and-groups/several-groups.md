# 多个组
{: .no_toc }

属于多个组的本地用户及其角色
{: .fs-6 .fw-300 }

本地用户可以属于多个组，并获得每个组的角色：角色以 `local/<group>` 的形式引用组。

在 **组** 选项卡上，**添加组** 会将用户加入另一个组，行菜单或复选框用于将其移出某个组。
用户至少要保留一个组。用户列表的每行菜单中也有 **添加到组**，作用相同。
