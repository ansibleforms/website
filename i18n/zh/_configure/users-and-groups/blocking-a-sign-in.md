# 阻止登录
{: .no_toc }

允许登录：在不删除任何内容的情况下阻止用户
{: .fs-6 .fw-300 }

**允许登录** 开关可以在不删除任何内容的情况下阻止一个用户，无论是本地用户还是来自目录的用户。

确认后将其关闭，该用户的会话会立即结束，所有登录都会被拒绝，直到您重新打开它。
用户列表的每行菜单中也有 **阻止登录** 和 **允许登录**，作用相同。

您不能阻止用户 `admin`，也不能阻止您自己的登录。
