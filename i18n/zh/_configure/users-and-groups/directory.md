# 目录用户和组
{: .no_toc }

LDAP、Entra ID 和 OIDC 的用户和组，按最近一次所见记录
{: .fs-6 .fw-300 }

LDAP、Entra ID 或 OIDC 用户的页面位于 `/settings/users/<source>/<name>`，来源为 `ldap`、`azuread` 或 `oidc`，
例如 `/settings/users/ldap/jdoe`。它以只读方式显示该用户上次登录时记录的内容，
因为用户的身份及其所属的组由目录或身份提供商负责。

其选项卡与本地用户相同。**详情** 中有 **允许登录** 开关、用户名、来源、名称、
电子邮件、首次出现时间以及上次登录时间。**组** 列出上次登录时的组。
**API 令牌** 列出该用户的 API 令牌，**撤销** 会立即使其中一个失效。

右上角的 **结束会话** 会立即让该用户在所有地方退出登录。**忘记** 会删除该记录，该记录会在用户下次登录时
重新出现；其作业、保存的作业和调度会保留。被阻止的用户不能被忘记，因为那样
会让他们重新进入：服务器会返回 `409`，因此请先允许其登录。

该记录中的组也是用户会话所使用的组，并且是实时读取的。忘记一个已登录的用户，
会让其在重新登录之前没有任何组，也没有这些组所赋予的角色。

目录组的页面位于 `/settings/groups/<source>/<name>`，为只读，包含选项卡 **详情**、
**用户**（上次登录时出现在该组中的用户）、**角色** 和 **表单**。
