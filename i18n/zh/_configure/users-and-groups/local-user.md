# 本地用户
{: .no_toc }

添加本地用户，以及其页面的各个选项卡
{: .fs-6 .fw-300 }

**添加用户** 会打开一个三步向导：**用户**（用户名、描述、电子邮件）、**密码** 和 **组**。

用户的页面 `/settings/users/<id>` 包含以下选项卡：

| 选项卡 | 显示的内容 |
|---|---|
| **详情** | **允许登录** 开关、用户名、描述、电子邮件，以及从 7.3.0 起的 **上次登录** |
| **组** | 用户所属的组 |
| **角色** | 用户拥有的角色，以及每个角色的来源：**直接**、**通过** 某个组，或 **所有人** |
| **表单** | 这些角色可以打开的表单 |
| **作业** | 用户启动的作业，最新的在前 |
| **保存的作业** | 用户为再次运行而保存的表单值 |
| **调度** | 用户通过稍后运行计划的作业 |
| **活动** | 审计日志记录的该用户的操作 |
| **API 令牌** | 用户的 API 令牌，以及每个令牌的创建时间、过期时间和上次使用时间；**撤销** 会立即使其中一个失效 |

从 7.3.0 起，本地用户的登录也会被记录，就像 LDAP 或 SSO 用户原本那样：**上次登录** 显示最近一次登录，
用户列表中对所有来源都有一个可排序的 **上次登录** 列，因此没人使用的账户会很显眼。被拒绝的登录不会被
记录，升级后尚未登录过的本地用户显示为 `–`。

**修改密码** 和 **删除** 位于右上角。用户 `admin` 永远不能被删除或重命名。
