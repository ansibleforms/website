# 谁管理运行器
{: .no_toc }

谁可以添加、修改和测试运行器
{: .fs-6 .fw-300 }

运行器会收到其运行的每个作业的凭据，因此只有 **admin** 角色才能添加、修改、打开或关闭以及删除运行器，
以及批准或拒绝请求加入的 RTE。拥有设置访问权限的用户可以查看和测试它们，但不能修改。

在 [配置种子](../seed/) 中声明的运行器在此页面上为只读：请改为在种子文件中修改。
