# 单个数据库的页面
{: .no_toc }

数据库的各个选项卡、查询它的表单、测试连接和删除
{: .fs-6 .fw-300 }

1. TOC
{:toc}

## 选项卡

数据库的页面将其对话框的各个步骤显示为选项卡，并额外显示查询它的表单：

| 选项卡 | 内容 |
|---|---|
| 详情 | **名称**，即字段的 `dbConfig` 给出的名称，以及 **描述** |
| 凭据 | 它用于连接的 **凭据**，即 连接 > 凭据 中类型为 **数据库** 的凭据，保存其数据库类型、主机、端口、数据库、TLS 和登录信息 |
| 使用者 | 查询它的表单，选项卡上显示数量，参见 [使用者](#used-by) |

每个选项卡都有自己的地址，例如 `/settings/databases/<id>/used-by`，因此链接或书签可以直接打开它。标题行的
搜索会同时筛选所有选项卡。

在 **凭据** 选项卡上，**添加凭据** 会创建一个类型为 **数据库** 的新凭据并选中它。密码一旦保存就不会再
显示：请在凭据中修改。

---

## 使用者

**使用者** 选项卡列出其字段查询该数据库的表单，即应用从表单中读取到的内容。

| 列 | 显示内容 |
|---|---|
| 表单 | 表单，点击某一行即可打开它 |
| 描述 | 表单的描述 |
| 字段 | 该表单中 `dbConfig` 指定该数据库的字段 |

当字段的 `dbConfig` 指定该数据库，或像 7.5.0 之前编写的表单那样指定其凭据时，该字段就会被计入。两者
通过同一个凭据连接，因此都会列出。没有时，选项卡显示 **没有表单查询此数据库。**

---

## 测试连接和删除

右上角的按钮作用于已保存状态的数据库。

**测试连接** 使用其凭据连接，运行其数据库类型最简单的查询，然后在消息中给出结果：
**&lt;name&gt; connection ok**，或失败的原因。它与凭据本身的 **测试连接** 是同一个测试。

**删除** 会先确认，然后删除数据库并返回列表。其凭据保留在 **连接 > 凭据** 下。
旁边的 **保存** 用于保存详情和凭据选项卡。
