# 添加公告
{: .no_toc }

两步向导：先填写消息，再设置显示时间
{: .fs-6 .fw-300 }

**添加公告** 会打开一个两步向导。**消息** 一步询问公告的内容：

| 字段 | 含义 |
|---|---|
| **消息** | 公告文本，最多 500 个字符。必填。 |
| **类型** | 公告的颜色和图标：蓝色表示信息（默认），琥珀色表示警告，红色表示危险 |

**时间** 一步询问公告何时显示：

| 字段 | 含义 |
|---|---|
| **开始日期** | 从此时刻开始显示。留空则立即显示。 |
| **结束日期** | 到此时刻隐藏并被删除。留空则一直保留，直到您将其删除。 |

结束日期必须晚于开始日期，并且必须是将来的时间。
