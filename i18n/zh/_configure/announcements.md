# 公告
{: .no_toc }

显示在页眉下方、面向所有人的消息，例如维护窗口，每条消息从开始时间显示到结束时间
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

面向管理员：在 **设置 > 外观 > 公告** 中，向每位用户通知维护窗口或故障事件。

该页面需要 `showSettings` 或 `showAppearanceSettings` 角色选项。从 7.3.0 起，公告是一个列表，每条公告都有自己的页面和
**已启用** 开关。

---

| 页面 | 内容 |

| [列表](announcements/list.html) | 尚未结束的公告、列表的各列，以及公告的页面 |
| [添加公告](announcements/adding-one.html) | 两步向导：先填写消息，再设置显示时间 |

## 显示位置

公告以一行文字的形式显示在每个页面的页眉下方，面向所有已登录的用户，并按其类型显示对应的颜色。

多条已启用的公告可以同时显示，最新的排在最前。登录页面和嵌入在其他网站中的表单不显示任何公告。

每条公告都有一个关闭按钮。关闭的公告在该浏览器标签页中保持关闭，直到标签页被关闭，或者
其消息或结束日期发生变化。保存后的公告会立即推送到所有已打开的浏览器；到达开始日期或结束日期的公告
会在一分钟内在这些浏览器中显示或隐藏。
