# 单个凭据的页面
{: .no_toc }

凭据的各个选项卡，以及哪些地方在使用它
{: .fs-6 .fw-300 }

凭据的页面将其对话框的各个步骤显示为选项卡，并额外显示哪些地方在使用它：

| 选项卡 | 内容 |
|---|---|
| 详情 | 名称和描述。 |
| 类型 | 凭据的用途。 |
| 登录 | 其类型的所有字段，与对话框的 **登录** 步骤相同：用户、密码，以及登录目标（主机和端口、数据库、邮件服务器、目录的服务器、租户或颁发者、服务器地址及其 TLS）。CyberArk 凭据还包括 AppID、客户端证书和密钥。从 7.6.0 起，还包括其登录方式的选择，以及 SSH 凭据的私钥和密码短语。 |
| 存储 | 数据库或密钥库，以及密钥库和引用。不适用于 CyberArk 和 HashiCorp Vault。 |
| 使用者 | 引用此凭据的所有对象：密钥库、通知通道、仓库、LDAP 目录、SSO 提供商、运行器、[数据库](../databases.html)（从 7.5.0 起）、聊天助手、表单以及设计器中的工作流。点击某一行即可打开它。 |

密码在 **登录** 选项卡中输入，保存后永远不会再显示：留空则保留已保存的密码。CyberArk 凭据的
客户端密钥同样如此；从 7.6.0 起，SSH 凭据的私钥和密码短语也是如此。

从 7.6.0 起，这只在登录方式的选择保持不变时成立。一旦改变（SSH 从 **私钥** 改为 **密码** 或反之，SMTP 从 **无需登录** 改为
**登录**，Entra ID 从 **证书** 改为 **密钥** 或反之，从 **令牌** 改为 **密码** 或反之），已存储的内容都不再适用：新选择所需的
新密钥为必填，**保存** 会要求输入。改为 **密码** 的 SSH 凭据会在 **保存** 时删除已存储的私钥及其密码短语，选项卡在该选择下方
也会这样说明。在 **存储** 选项卡中选择 **写入键** 时，只提供带密码的选择，参见 [凭据如何登录](types.html#how-a-credential-signs-in)。

右上角有 **测试连接**（仅限数据库凭据）、**删除** 和 **保存**。

从 7.3.0 起，只要 **使用者** 中列有任何内容，**删除** 和改名都会被拒绝，参见 [正在使用的凭据](../credentials.html#credentials-in-use)。

在 [配置种子](../seed/) 中声明的凭据在此页面上为只读：请改为在种子文件中修改。
