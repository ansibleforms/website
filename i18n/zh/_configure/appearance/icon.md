# 图标
{: .no_toc }

浏览器标签页和书签中您自己的图标
{: .fs-6 .fw-300 }

**图标** 用于替换浏览器标签页和书签中的 AnsibleForms 图标：

| 规则 | 值 |
|---|---|
| 类型 | PNG、ICO、SVG、WEBP、GIF 和 JPEG |
| 文件大小上限 | 256 KB |
| 最佳效果 | 至少 64 × 64 px 的正方形图片，或 SVG |

在 **新图标** 下选择一个文件，然后点击 **上传**；**删除自定义图标** 会恢复默认图标。
