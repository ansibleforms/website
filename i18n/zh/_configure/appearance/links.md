# 链接
{: .no_toc }

页眉中的链接，包括内置链接和您自己的链接
{: .fs-6 .fw-300 }

**链接** 为所有已登录的用户设置页眉中的链接，分为两个选项卡。

**内置** 中有 **设计器** 开关，保存在 [`SHOW_DESIGNER`](../customization/features.html#env_SHOW_DESIGNER) 中，
无需重启即可生效。关闭后，所有人都无法使用设计器：它的链接、页面和 API 都会消失。

**自定义** 中保存您自己的链接，例如 wiki、运维手册或支持门户。**添加链接** 会添加一行，包含以下字段：

| 字段 | 含义 |
|---|---|
| **图标** | 显示在标签前的图标，从列表中选择 |
| **标签** | 链接的文本 |
| **地址** | 一个网站（`https://…`）或应用中的一个页面（`/forms/all`） |
| **新标签页** | 在新的浏览器标签页中打开链接 |

每行的按钮用于移动它：**→** 把该链接放进上方的链接中，上方的链接随后在页眉中以菜单形式打开，
**←** 把它移回页眉，上下箭头则上下移动它（若是菜单，则连同其中的链接一起移动）。
菜单本身不需要地址。

在内置链接之后，页眉最多容纳 5 个您自己的链接，每个菜单中最多 10 个。
