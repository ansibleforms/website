# 徽标
{: .no_toc }

页眉中您自己的徽标
{: .fs-6 .fw-300 }

**徽标** 用您自己的图片替换页眉中的 AnsibleForms 徽标，在所有主题下都会显示：

| 规则 | 值 |
|---|---|
| 类型 | PNG、JPEG、WEBP、GIF 和 SVG |
| 文件大小上限 | 900 KB |
| 在页眉中的尺寸 | 最大 200 × 33 px，保持原有比例 |

在 **新徽标** 下选择一个文件进行预览，然后点击 **上传**。**当前徽标** 显示正在使用的徽标及其在页眉中显示的尺寸。
**移除自定义徽标** 会恢复默认徽标，默认徽标会随主题变化。
