## 谁接受了

每次接受都会按用户和版本记录下来，版本页面的 **接受记录** 选项卡会列出它们，最新的在前：

| 列 | 含义 |
|---|---|
| **用户** | 用户名 |
| **登录方式** | 他们的登录方式：本地、LDAP、Microsoft Entra ID 或 OpenID Connect |
| **接受时间** | 接受的时间 |
| **IP 地址** | 来源地址 |
| **浏览器** | 他们的浏览器 |

---

## 请用户再次接受

从 7.3.0 起，可以只请选定的用户再次接受某个版本，而无需请所有人重新接受。

在行菜单中，或对列表中勾选的行使用 **再次请求**，确认后会清除这些接受记录：这些用户会在下一次请求时再次看到
免责声明，无需重新登录。与所有表格一样，该列表也可以导出。

[审计日志](../production/logs.html#audit-trail) 还会记录每次接受、每次拒绝以及免责声明的每次更改。
