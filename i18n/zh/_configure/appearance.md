# 外观
{: .no_toc }

默认值、名称、徽标、浏览器图标、页眉链接以及徽标旁的标签
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

面向管理员：在 **设置 > 外观** 中让实例呈现您自己的样式，需要 `showSettings` 角色选项。
仅有 `showAppearanceSettings` 角色选项也可以打开这些页面（包括公告），但不能打开其余设置。

这一组页面包括 **默认值**、**名称**、**徽标**、**图标**、**链接**、**标签** 和 **公告**；
公告有自己单独的页面，见 [公告](announcements.html)。保存后的默认值、名称、链接或标签
会立即在所有已打开的浏览器中生效。

---

## 本节内容

| 页面 | 内容 |
|---|---|
| [默认值](appearance/defaults.html) | 为未作选择的用户设定的主题、语言、时区和日期格式 |
| [名称](appearance/name.html) | 浏览器标签页和登录页面上显示的应用名称 |
| [徽标](appearance/logo.html) | 页眉中您自己的徽标 |
| [图标](appearance/icon.html) | 浏览器标签页和书签中您自己的图标 |
| [链接](appearance/links.html) | 页眉中的链接，包括内置链接和您自己的链接 |
| [标签](appearance/labels.html) | 徽标旁标明当前实例的标签；7.2 及更早版本中只有一个“环境”标签 |
