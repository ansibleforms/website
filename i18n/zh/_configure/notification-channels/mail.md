# 邮件
{: .no_toc }

SMTP 服务器、默认服务器及其登录信息
{: .fs-6 .fw-300 }

邮件通道就是一台 SMTP 服务器。您可以保留多个；标记为 **默认** 的那个，是表单未引用任何邮件通道时应用发送
邮件所用的服务器。第一个邮件通道会成为默认通道，**设为默认** 可以更改默认通道。

| 步骤 | 字段 | 含义 |
|---|---|---|
| 凭据 | 凭据 | 必填。[连接 > 凭据](../credentials.html) 中的一个 **smtp** 凭据：邮件服务器、其端口和 TLS，以及登录信息。对于无需登录的中继，使用没有用户的 smtp 凭据。 |
| 发件人 | 发件人 | 收件人看到的发件地址。 |

邮件通道页面 **详情** 选项卡上的 **默认** 开关会将其设为默认，与 **设为默认** 的作用相同。
当没有邮件通道作为默认通道，或默认通道已关闭时，会使用配置种子中的邮件设置。
