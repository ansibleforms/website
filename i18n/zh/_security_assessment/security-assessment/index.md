# 安全评估
{: .no_toc }

面向安全审查：安全措施、开发流程和安全公告
{: .fs-6 .fw-300 }

---

## 简而言之

AnsibleForms 运行 playbook 并保管其凭据，因此它是您信任链的一部分：

* 它是**自托管**的：运行在您的基础设施上，数据保存在您的数据库中，不向开发者发送任何内容。
* 它是**开源**的（GPL-3.0）：代码、其流水线以及每条公告都是公开的。
* 每个存储的机密都经过**加密**，每项变更都经过**审计**，每个请求都会检查**角色**。
* 漏洞**私下报告**，在每个受支持的版本中修复，并**公开发布**。
