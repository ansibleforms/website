# 账户
{: .no_toc }

您当前以谁的身份登录
{: .fs-6 .fw-300 }

---

账户视图显示您当前以谁的身份登录，以及决定您访问权限的因素：

- **用户名**和**登录类型**：本地账户、LDAP、Microsoft Entra ID 或 OpenID Connect。
- **组**：随您的登录而来的组，例如 `local/admins` 或 `ldap/Domain Admins` 。
- **角色**： `config.yaml` 中与这些组和您的用户匹配的角色。它们决定了
  您能看到哪些表单以及拥有哪些选项。
