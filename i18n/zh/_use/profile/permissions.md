# 权限
{: .no_toc }

您的角色允许您做什么
{: .fs-6 .fw-300 }

---

角色选项按选项卡分组，每个选项卡都会显示您拥有其中多少个选项，例如 `5/8` ：

| 选项卡 | 相关选项 |
|---|---|
| **访问和集成** | 登录、聊天助手、MCP 服务器、文件上传和 API 令牌 |
| **设计器** | 打开设计器，以及编辑表单、playbook、工作流、清单和变量文件 |
| **作业** | 查看作业及其 extravars 或工件，重新运行、删除、调度和保存作业 |
| **设置** | 设置页面、日志、审计日志和备份 |
| **其他** | 手动在角色中设置、不属于其他任何选项卡的选项；始终是最后一个选项卡 |

其他选项卡按字母顺序排列。每个选项卡都是一个表格，包含**设置**（选项）、**描述**
（作用）和**您的权限**三列：**允许**或**不允许**。因另一个选项而生效的选项会在
其描述下方注明：**已包含在**您拥有的某个选项**中**会开启它，**需要**您缺少的某个选项则会让它保持关闭。

选项来自您在 `config.yaml` 中各个角色的 `options` ；[角色](../config/roles.html)页面介绍了它们
如何组合。
