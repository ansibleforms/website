## 偏好设置项

偏好设置视图可以改变 AnsibleForms 在您面前的外观。每个选择都保存在您做出选择的
浏览器中，因此换一个浏览器或电脑时会从默认值开始。

| 设置 | 可选项 | 也可以在这里设置 |
|---|---|---|
| 语言 | Català、Deutsch、English、Español、Français、Italiano、Nederlands、Polski、Português、日本語（日语）、简体中文 | 标题栏中的旗帜 |
| 主题 | 跟随浏览器、浅色、深色，或颜色（标题栏使用您选择的颜色） | 标题栏中的太阳图标 |
| 表单视图 | 磁贴或列表 | 表单页面上的按钮 |
| 时区 | UTC、此浏览器的时区，或按名称选择的任意时区 | 仅限此处 |
| 日期格式 | `YYYY-MM-DD` 、 `DD/MM/YYYY` 、 `MM/DD/YYYY` 或 `DD.MM.YYYY` | 仅限此处 |
| 桌面通知 | 开或关 | 仅限此处 |

从 7.3.0 起，该视图分为多个选项卡，每个选项卡都有自己的地址（ `/profile/preferences/<tab>` ）：**外观**（语言、主题和表单
视图）、**日期和时间**（时区和日期格式）以及**通知**。它们上方的搜索框会在所属选项卡的名称下列出匹配的
设置。选择在点击**保存**之前只是草稿，带着未保存的修改离开该视图时会先询问确认。

**跟随浏览器**会随浏览器切换浅色或深色，并跟着浏览器一起变化。从 7.3.0 起它是默认主题，除非您的
管理员选择了其他主题。在此处或标题栏的主题菜单中，将鼠标悬停在**颜色**主题的某个颜色上，会以该颜色预览应用，
指针离开调色板时会恢复之前的主题；只有点击之后才会真正改变。

## 桌面通知

从 7.3.0 起，对于角色设置了 `showJobs` 的用户，**通知**选项卡可以在此浏览器中开启桌面通知。

浏览器会在第一次时请求权限。当浏览器阻止该站点的通知时，开关保持关闭，并说明如何
允许通知；使用普通 `http` 的站点则完全无法显示通知。开启后，会在以下情况发出通知：

| 时机 | 通知内容 | 点击后 |
|---|---|---|
| 您运行的作业结束时 | 表单及其结果，例如 *Patch Linux servers: 成功*，以及作业编号和持续时间 | 将该标签页切换到前台并显示该作业 |
| 有作业等待您审批时 | 表单、作业编号以及运行者，并带有**批准**和**拒绝**按钮 | 打开等待审批的作业列表 |

**批准**和**拒绝**按钮在 Chrome 和 Edge 中显示；Firefox 和 Safari 显示的通知不带这些按钮，使用
自签名证书的站点也是如此，因为这些按钮需要 service worker。只有在 AnsibleForms 标签页打开时才会收到通知，
即使在后台也可以：所有标签页都关闭后就不会再发送任何通知。无论打开了多少个标签页，每条通知只显示一次，并且
多步骤作业的各个步骤以及您正在查看的作业不会发出通知。

## 时区

AnsibleForms 中的日期和时间都按您选择的时区显示。这包括作业的开始
和结束时间、审计日志、状态页面、备份、保存的作业，以及 API
令牌的过期时间。修改时区会立即更新每个页面，无需重新加载。

在您选择之前，适用管理员为所有人设置的时区（**设置 > 外观 > 默认值**，参见
[外观](../appearance.html)），未修改时为 **UTC**。**此浏览器**跟随您电脑的时区，
列表中包含所有按名称列出的时区，例如 `Europe/Madrid` 。卡片会以所选的时区和格式显示当前时间。

---

## 日期格式

日期格式决定每个日期中日期部分的显示方式，每个选项都以今天的日期作为示例： `YYYY-MM-DD`
（2026-10-12）、 `DD/MM/YYYY` 、 `MM/DD/YYYY` 或 `DD.MM.YYYY` 。在您选择之前，适用管理员设置的默认日期格式，
未修改时为 `YYYY-MM-DD` 。与其他选项一样，它保存在此浏览器中。

---

## 哪些内容保留服务器时间

有两个例外会保留服务器自己的时间：

- **服务器日志和作业输出**是文本，其中包含服务器写入的时间。
- **您输入的时间**，例如计划作业的运行时间，以及 cron 调度，都与
  以前一样。
