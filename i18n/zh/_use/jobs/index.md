# 作业
{: .no_toc }

跟踪、中止、重新运行、批准和删除由表单启动的作业
{: .fs-6 .fw-300 }

---

面向所有运行表单的用户：什么是作业、在哪里找到它，以及谁能看到它。

---

## 什么是作业

作业是表单的一次运行：表单一经提交，AnsibleForms 就会记录它及其状态、extravars 和输出。

每个作业保存：

* 它运行的**表单**以及运行它的**用户**（包括用户类型，例如 `local` 或 `ldap` ）；
* 它的**作业类型**和**状态**，以及**开始时间**和**结束时间**；
* 它的**输出**、运行时使用的 extravars 和凭据，以及在表单中输入的字段值。

多步骤表单会为表单创建一个作业，并为每个步骤各创建一个作业。各步骤关联到主作业，并列在其下方。

同样的作业也可以通过 [REST API](../api/jobs.html) 运行、跟踪和管理。

---

## 作业页面

标题栏中的**作业**链接会打开所有作业的列表，最新的排在最前（ `/jobs/all` ）。只有角色设置了 `showJobs` [角色选项](../config/roles.html#role-options)的用户
才能看到该页面及其链接。

![作业列表](../assets/screenshots/job-log.jpg)

左侧菜单按时间对作业进行分类，每个条目都显示作业数量；状态条目会按该状态筛选列表：

| 部分 | 菜单条目 | 显示内容 |
|---|---|---|
| **过去** | **成功** | 状态为 `success` 的作业 |
| | **失败** | 状态为 `failed` 的作业 |
| | **已中止** | 状态为 `aborted` 的作业 |
| | **已拒绝** | 状态为 `rejected` 的作业 |
| | **已放弃** | 状态为 `abandoned` 的作业 |
| **现在** | **运行中** | 状态为 `running` 的作业 |
| | **等待审批** | 状态为 `approve` 的作业；有作业等待时计数变为橙色 |
| **未来** | **已计划** | [调度](schedules.html)页面（角色选项 `allowScheduledJobs` ） |
| | **已保存** | [保存的作业](stored-jobs.html)页面（角色选项 `allowStoredJobs` ） |

菜单中没有显示所有作业的条目：标题栏中的**作业**链接会显示所有作业，包括 `warning` 作业。

在表格上方的标题行上：

* **搜索框**保留那些显示的列中包含该文本（不区分大小写）的作业，或者其某个步骤的 ID
  或目标包含该文本的作业；
* **删除**（带有已勾选作业的数量）会一起删除第一列中勾选的作业；
* **列**用于显示或隐藏 `id` 、 `form` 、 `job type` 、 `status` 、 `start time` 、 `end time` 、 `duration` 和 `user` 列；
  正在运行的作业的持续时间会不断增加；
* **刷新**会重新加载列表。

列表加载最新的作业，数量由 [`JOBS_LIST_SIZE`](../customization/features.html#env_JOBS_LIST_SIZE) 设置决定
（**设置 > 系统 > 常规**，**作业**选项卡，默认 `1000` ）；其分页、搜索和筛选都只覆盖这些作业。

每一列都可以排序，并有自己的筛选字段。多步骤作业在其 `form` 前面有一个箭头，可展开
其各个步骤；点击行的其余部分会打开该作业。

标题栏中的铃铛统计等待您审批的作业数量，并打开**等待审批**列表。对于能看到
运行器的用户，它还会统计[等待批准的运行器](../runners/registration.html#approving-an-rte)，即请求加入的 RTE，
当只有运行器在等待时，会打开**连接 > 运行器**。两者都在等待时，它会打开一个菜单，包含**等待批准的作业**和
**等待批准的运行器**，每项都带有其数量。

## 谁能看到哪些作业

用户能看到的作业取决于其角色：

| 用户 | 能看到 |
|---|---|
| 管理员（ `admin` 角色） | 所有作业 |
| 角色选项 `showAllJobLogs` | 所有作业 |
| 角色选项 `manageAllJobs` （从 7.3.0 起） | 所有作业，并且可以中止、删除和重新运行它们 |
| 其他任何用户 | 自己的作业，以及等待审批且审批指定了其某个角色的作业 |

在 7.2 及之前，每个用户都可以打开任何等待审批的作业，包括其 extravars 和输出；从 7.3.0 起，只有其所有者和
审批人才能打开。能看到作业并不意味着可以对它执行所有操作：中止、删除和重新运行其他用户的作业需要管理员或
`manageAllJobs` ，而 `showAllJobLogs` 只用于显示作业。删除还需要 `allowJobDeletion` ，重新运行还需要 `allowJobRelaunch` 。
