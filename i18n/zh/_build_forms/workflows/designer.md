# 在设计器中编辑
{: .no_toc }

绘制工作流，并在不运行任何内容的情况下试用
{: .fs-6 .fw-300 }

1. TOC
{:toc}

## 工作流部分

**设计器 > 工作流**在文件浏览器中列出工作流文件，并带有每个
[设计器](../designer/)部分都有的 YAML、可视化和预览选项卡。

- 工具栏中的 **`+` 按钮**会创建一个工作流文件，其中带有一个空工作流供您起步。
- **YAML** 按文件的原样显示它。其他选项卡也会保留注释和键的顺序。
- **可视化**把文件中的每个工作流绘制成一张图，名称和描述显示在图的上方。包含两个工作流的文件
  会把两者上下排列显示。
- **预览**是工作流的试运行：参见[试用](#trying-it-out)。

问题会列在图的上方，每个问题都带有一个链接，可在 YAML 中打开对应的行：指向不存在节点的链接、
循环，以及设计器不认识的 playbook、清单、凭据、运行器或仓库。

---

## 图

图从左向右阅读，从 **START** 到最后的节点。每个节点显示其标识符，并在下方显示
它运行的内容；连接按触发条件着色，如图内图例所示：成功时、失败时、
始终。

- **点击 START** 添加第一个节点：没有父节点的节点，工作流一开始就会运行。
- **点击节点**进行编辑。
- **点击连接**可以更改其触发条件，或者将其移除。

---

## 添加节点

新节点通过向导添加：在已有节点上选择**成功时新建节点**、**失败时新建节点**或**始终新建节点**，
或者点击 START 添加第一个节点。

1. **运行什么**：节点的标识符、**运行**（节点的类型，对于 playbook 节点还包括它在哪里运行）
   以及它运行的内容：playbook、模板或作业、工作流、审批的名称和超时，或者仓库。参见
   [节点在哪里运行](#where-a-node-runs)。
2. **如何运行**：运行设置：清单、凭据、限制、标签、详细程度、
   检查模式和差异模式、条件（**运行条件**）以及**取值自**（参见[工作流文件](file.html#run-settings)）。
3. **去向**：它在哪个节点之后运行，以及在什么条件下运行。

**创建**会把该节点添加到 YAML 中。

---

## 节点在哪里运行

**运行**在一个列表中说明节点运行什么以及在哪里运行：**RTE 上的 playbook**、**AWX 上的模板**、**Semaphore 上的
模板**、**Rundeck 上的作业**、**Jenkins 上的作业**，然后是**工作流**、**审批**和**仓库拉取**。

| 运行 | 其下方的字段 | 运行器 |
|---|---|---|
| **RTE 上的 playbook** | **Playbook**：设计器中的某个 playbook | **默认 RTE**，或按名称指定的 RTE 运行器 |
| **AWX 上的模板**（包括 AAP 和 Ascender） | **模板**：手动输入的模板名称 | AWX 运行器，各自带有其类型 |
| **Semaphore 上的模板** | **模板**：手动输入的模板名称 | Semaphore 运行器 |
| **Rundeck 上的作业**或 **Jenkins 上的作业** | **作业**：手动输入的作业名称 | Rundeck 或 Jenkins 运行器 |

- **RTE 上的 playbook** 始终可选；其他选项只有在实例拥有该类型的[运行器](../runners.html)时才会出现。
- **运行器**只列出该类型的运行器，默认运行器会被标记并预先选中（没有默认时选中名称排在最前的）。
- 选择另一个运行位置会清空节点运行的内容，需要重新选择。
- 如果设计器不认识节点的运行器，节点会显示 **该运行器上的模板或作业**。

工作流文件不会改变：这样的节点是一个带有 `runner:` 的 `job_template` 节点（参见
[工作流文件](file.html#run-settings)）。

## 编辑节点

点击节点会打开其对话框，包含四个选项卡：

| 选项卡 | 内容 |
|---|---|
| **运行什么** | 标识符、**运行**、运行的内容，对于 playbook 节点还有运行器 |
| **如何运行** | 运行设置；凭据从列表中选择，每个都用 `+` 添加 |
| **在其后运行** | 指向该节点的连接，以及**所有父节点必须汇合** |
| **之后运行** | 从该节点出发的连接，以及**连接到已有节点：** 和**连接到新节点：** |

**在 YAML 中显示**会在 YAML 中打开该节点，**移除节点**会将其连同连接一起移除。每次修改都会立即写入
YAML；**保存**会保存文件。

---

## 试用

**预览**选项卡会按照 AWX 的规则把工作流完整演练一遍，而不运行任何内容。

每个节点一开始都是成功。点击某个节点让它失败，再次点击让它成功；图随后会显示
哪些节点会运行、哪些不会运行，以及工作流是否会失败。**重置**会让所有节点重新变为成功。
