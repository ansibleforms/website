# Testar um canal
{: .no_toc }

Enviar teste, e o que prova
{: .fs-6 .fw-300 }

**Enviar teste** envia uma notificação de teste através do canal tal como está guardado, por isso guarde primeiro as suas alterações. Também funciona num canal
que está desligado. Num canal de email,
a caixa de diálogo pede o endereço para onde enviar; os outros publicam no seu próprio canal. A caixa de diálogo mostra se funcionou,
e o motivo quando não funcionou.
