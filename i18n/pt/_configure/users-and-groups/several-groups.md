# Vários grupos
{: .no_toc }

Um utilizador local em vários grupos, e as suas funções
{: .fs-6 .fw-300 }

Um utilizador local pode pertencer a vários grupos, e recebe as funções de todos eles: as funções nomeiam um grupo como `local/<group>`.

No separador **Grupos**, **Adicionar grupo** adiciona o utilizador a outro grupo, e o menu de uma linha ou as caixas de verificação removem um.
Um utilizador mantém pelo menos um grupo. A lista de utilizadores tem **Adicionar a um grupo** no menu de cada linha para o mesmo efeito.
