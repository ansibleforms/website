# Adicionar um
{: .no_toc }

O assistente de dois passos: a mensagem e, depois, quando aparece
{: .fs-6 .fw-300 }

**Adicionar anúncio** abre um assistente de dois passos. **Mensagem** pergunta o que diz:

| Campo | Significado |
|---|---|
| **Mensagem** | O texto, no máximo 500 caracteres. Obrigatório. |
| **Tipo** | A sua cor e o seu ícone: azul para Informação (o predefinido), âmbar para Aviso, vermelho para Perigo |

**Quando** pergunta quando aparece:

| Campo | Significado |
|---|---|
| **Data de início** | Aparece a partir deste momento. Deixe-a vazia para o mostrar de imediato. |
| **Data de fim** | Neste momento é ocultado e eliminado. Deixe-a vazia para o manter até o eliminar. |

A data de fim tem de ser posterior à data de início e estar no futuro.
