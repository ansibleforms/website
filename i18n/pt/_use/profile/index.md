Para todos os utilizadores: a sua própria conta, preferências, palavra-passe, permissões e tokens de API.

Abra o seu perfil a partir do avatar no canto superior direito: **Perfil**.

---

## Abrir uma vista

O menu da esquerda lista as vistas do perfil por ordem alfabética. Cada vista tem o seu próprio endereço,
pelo que pode ligar diretamente para ela:

| Vista | Endereço |
|---|---|
| Conta | `/profile/account` |
| Tokens de API | `/profile/token` |
| Palavra-passe | `/profile/password` |
| Permissões | `/profile/permissions` |
| Preferências | `/profile/preferences` |

`/profile` sozinho abre a primeira vista do menu. As vistas que as suas funções não permitem ficam ocultas; o seu endereço abre antes a primeira
vista. **Tokens de API** só é mostrado quando uma das suas funções tem a opção de função `allowApiTokens`.
